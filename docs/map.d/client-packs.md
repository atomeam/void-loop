The client packs, each a card offline that says what Verse takes on for a business process: `skills/ownership-pack.js` (what Verse owns and what the client keeps), `skills/automation-pack.js` (the automations Verse would run for a process), `skills/lift-summary.js` (a short client summary of the systems Verse owns and the work that drops), `skills/docs-pack.js` (the client documentation for a system: status, ownership, monitors, next steps) and `skills/feedback-loop.js` (client feedback on a shipped slice turned into the next change). `skills/reuse-tools.js` (lists run 16) is one family of `reuse-pack` and `connect-pack`, the existing tools to reuse before building; both names still answer and `tools/reuse-tools-family.test.mjs` keeps every ask on the member it reached before. `tools/versus-useful.mjs` is the "is it real and useful?" check: a phone-width visit judged by a free model, and a missing model counts as no.
