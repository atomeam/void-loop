The stranger gate (`tools/stranger-gate.mjs`, `tools/stranger-gate.test.mjs`) checks a changed page, tool, game or card the way a stranger would, on every pull request and nightly on the live site. It calls the probes already here: `tools/quality-measure.mjs` for a page (phone and desktop, errors, the main control, pictures, layout, the speed budget in `lib/quality.js`), `tools/game-fun.mjs` for a short play of a game, `lib/seo-audit.js` for a missing title, `tools/handoff-scan.mjs` for a new page with no handoff tag, and `tools/capability-sweep/list.json` to tell a tool from a page. A model judges only when a Groq or Cloudflare AI secret is already set (`tools/studio-make.mjs`). A failure on a pull request is a plain list. The nightly run opens one queue job per failure. Screenshots and `stranger.json` are the run's artifact.
