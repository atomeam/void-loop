The Tower target "a top AI assistant": `tools/assistant-exam.mjs` puts a fixed set of 20 real questions (`tower.assistant.json`, owner-only, with an assistant-quality reference answer for each) to the live agent and scores every answer 0-100 on correctness (the facts a right answer holds), usefulness (not a dodge, the practical parts, the shape asked for) and clarity (no rambling, filler, raw data or cut-off endings) with pattern checks, not a model. `--check` proves each reference scores 100; `--live --write` records the three marks on the `top-assistant` target in `tower.universe.json` (kind `answers`, bar 94, `lib/universe.js`) and queues each question with a gap (a score under 90) in `background` as a build job in plain words. Like every kind it also carries the graphics and 60 fps checks (the look of the agent page), so Verse beats the target only when right, useful, clear, graphics and performance all beat 94.
