The Tower target "a top AI assistant": `tools/assistant-exam.mjs` puts a fixed set of 20 real questions (`tower.assistant.json`, owner-only, with an assistant-quality reference answer for each) to the live agent and scores every answer 0-100 on correctness (the facts a right answer holds), usefulness (not a dodge, the practical parts, the shape asked for) and clarity (no rambling, filler, raw data or cut-off endings) with pattern checks, not a model. `--check` proves each reference scores 100; `--live --write` records the three marks on the `top-assistant` target in `tower.universe.json` (kind `answers`, bar 94, `lib/universe.js`) and queues each question with a gap (a score under 90) in `background` as a build job in plain words. Like every kind it also carries the graphics and 60 fps checks (the look of the agent page), so Verse beats the target only when right, useful, clear, graphics and performance all beat 94.

The held-out set: `tower.heldout.json` (owner-only) is a pool of 112 questions over health, money, writing, coding, how-to, local and current events, with a reference answer for each. Three times a day (the 09:00, 13:00 and 19:00 house lanes, guard `assistant`) `tools/heldout-exam.mjs` samples 20 the agent has been asked least, so the questions change from run to run. Pattern checks and a blind pairwise model judge (`tools/answer-judge.mjs`: Gemini, then the free Workers AI review model; Verse's answer and the reference in a random order) score each run. A run beats the reference when each pattern mark is above 94 and the judge rates Verse at least equal with no mark more than 5 behind; a run with fewer than 15 answers judged counts for nothing. The bar is 3 such runs in a row: the Tower check `heldout` stays at 93 or less until then. Gaps queue by area and what was lacking, never by question, so the held-out set cannot be tuned to.
