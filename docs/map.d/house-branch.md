A house lane starts by making its branch fresh: `tools/house-branch.mjs` (called from `tools/house-loops.mjs`, `tools/house-branch.test.mjs`) deletes `house/<lane>` on origin when it has no open pull request (a branch left over from a merged PR cannot take the new patch, so the lane shipped nothing), in GitHub Actions only, and never one with an open PR or when GitHub gives no answer. No workflow file is edited: the workflow's own next step then opens a new branch from main and a new PR.
