`merge-flow.mjs` decides the next step for a pull request (merge, fix, wait, skip). `pr-fix.mjs` and `.github/workflows/pr-fix.yml` run Verse's free-model coder on a conflict, a red check, or a red main. Automerge merges without waiting for the suite. A red main starts a fix and does not freeze the queue. `no-approval-gate.mjs` fails if a CODEOWNERS file, a required approving review, or a merge hold comes back.
