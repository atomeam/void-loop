`house-loops.mjs` runs one house lane (`void-live-deploy/lib/house-loops.js`, `tools/house-loops.test.mjs`, `.github/workflows/house-loops.yml`, playbook `docs/playbooks/house-loops.md`). The lanes are broken links, page health, page speed, duplicate headings, a sentence under a heading, dataset dates, search titles, the next untested file, dependency advisories, the next page handoff, and the oldest open gap. Each writes `void-live-deploy/progress/loops/<id>.json`, listed on `/progress/`.
