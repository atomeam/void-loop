## Ownership changes, pivots and shutdowns

- 2018: "In 2018, Microsoft announced that for OneNote on Windows, the Universal Windows Platform (UWP) based OneNote for Windows 10, now renamed "OneNote for Windows 10", would be the default experience for Office users on Windows." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#OneNote_for_Windows_10))
- 2021: "In 2021, Microsoft announced that OneNote for Windows 10 would be discontinued and that they were working on migrating users and features to the desktop version." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#OneNote_for_Windows_10))
- 2025: "This feature has been discontinued in March 2025." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Overview))
- "The desktop application was renamed to simply OneNote, matching the other programs in Office 365." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#OneNote_for_Windows_10))

## Notable features

- "OneNote supports simultaneous editing of shared OneNote documents by multiple users when the document is stored in a shared folder in OneDrive." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Platform_support))
- "Dropbox was supported for some time as a sync protocol, but after Windows Live Mesh was discontinued, OneNote supported it for cloud-based storage and synchronization of OneNote files." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Platform_support))
- "OneNote clients, including the OneNote web app of Office Online, can view and edit them." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Platform_support))

## Controversies

- "Christopher Dawson reviewed OneNote 2010, titling his favorable review "OneNote is Office 2010's killer app in education"." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Reception))
- "He speculated that the app would be particularly useful as a tool for student notetaking." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Reception))
- "In 2022 Microsoft has merged the OneNote and OneNote for Windows 10 apps into a single version, the older version OneNote for Windows 10 will continue to work but it will not get new updates, noting that "it will reach end-of-support in October 2025"." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Reception))
- "In 2023, Tom Warren of The Verge highlighted a new digital ink and pen feature addition gestures, and an AI-powered copilot feature to help you summarize pages or section of notes." ([source](https://en.wikipedia.org/wiki/Microsoft_OneNote#Reception))
