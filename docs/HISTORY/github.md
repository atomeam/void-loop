## Key milestones

- 2007: "The development of the GitHub platform began on October 19, 2007." ([source](https://en.wikipedia.org/wiki/GitHub#Founding))
- 2007: "The company, GitHub, Inc., was formed in 2007 and is located in San Francisco." ([source](https://en.wikipedia.org/wiki/GitHub#History))
- 2008: "The site was launched in April 2008 by Tom Preston-Werner, Chris Wanstrath, P." ([source](https://en.wikipedia.org/wiki/GitHub#Founding))
- 2008: "Hyett, Tom Preston-Werner, and Scott Chacon using Ruby on Rails, and started in February 2008." ([source](https://en.wikipedia.org/wiki/GitHub#History))
- 2009: "On February 24, 2009, GitHub announced that within the first year of being online, GitHub had accumulated over 46,000 public repositories, 17,000 of which were formed in the previous month." ([source](https://en.wikipedia.org/wiki/GitHub#History))
- 2010: "In 2010, GitHub was hosting 1 million repositories." ([source](https://en.wikipedia.org/wiki/GitHub#History))
- 2011: "ReadWriteWeb reported that GitHub had surpassed SourceForge and Google Code in total number of commits for the period of January to May 2011." ([source](https://en.wikipedia.org/wiki/GitHub#History))
- 2013: "On January 16, 2013, GitHub passed the 3 million users mark and was then hosting more than 5 million repositories." ([source](https://en.wikipedia.org/wiki/GitHub#History))
- 2015: "In 2015, GitHub opened an office in Japan, its first outside of the U.S." ([source](https://en.wikipedia.org/wiki/GitHub#History))
- 2018: "On February 28, 2018, GitHub fell victim to the third-largest distributed denial-of-service (DDoS) attack in history, with incoming traffic reaching a peak of about 1.35 terabits per second." ([source](https://en.wikipedia.org/wiki/GitHub#History))

## Notable features

- "Projects on GitHub can be accessed and managed using the standard Git command-line interface; all standard Git commands work with it." ([source](https://en.wikipedia.org/wiki/GitHub#Services))
- "GitHub also allows users to browse public repositories on the site." ([source](https://en.wikipedia.org/wiki/GitHub#Services))
- "Multiple desktop clients and Git plugins are also available." ([source](https://en.wikipedia.org/wiki/GitHub#Services))
- "GitHub also provides some software as a service (SaaS) integrations for adding extra features to projects." ([source](https://en.wikipedia.org/wiki/GitHub#GitHub_Marketplace_service))
- "Those services include: Waffle.io: project management for software teams, which allows users to automatically see pull requests, automated builds, reviews, and deployments across repositories." ([source](https://en.wikipedia.org/wiki/GitHub#GitHub_Marketplace_service))
- "Rollbar: provides real-time debugging tools and full-stack exception reporting." ([source](https://en.wikipedia.org/wiki/GitHub#GitHub_Marketplace_service))

## Controversies

- "On December 4, 2014, Russia blacklisted GitHub.com because GitHub initially refused to take down user-posted suicide manuals." ([source](https://en.wikipedia.org/wiki/GitHub#Censorship))
- "After a day, Russia withdrew its block, and GitHub began blocking specific content and pages in Russia." ([source](https://en.wikipedia.org/wiki/GitHub#Censorship))
- "On December 31, 2014, India blocked GitHub.com along with 31 other websites over pro-ISIS content posted by users; the block was lifted three days later." ([source](https://en.wikipedia.org/wiki/GitHub#Censorship))
- "On October 8, 2016, Turkey blocked GitHub to prevent email leakage of a hacked account belonging to the country's energy minister." ([source](https://en.wikipedia.org/wiki/GitHub#Censorship))
- "In 2012, Linus Torvalds, the original developer of Git, highly praised GitHub, stating, "The hosting of github [sic] is excellent." ([source](https://en.wikipedia.org/wiki/GitHub#Reception))
- "They've done a good job on that." ([source](https://en.wikipedia.org/wiki/GitHub#Reception))
