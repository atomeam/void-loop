## Key milestones

- 1998: "Reverso has been active since 1998, with the aim of providing high-quality online translation and linguistic tools to corporate and mass markets." ([source](https://en.wikipedia.org/wiki/Reverso_(language_tools)#History))
- 2013: "In 2013 it released Reverso Context, a bilingual dictionary tool based on big data and machine learning algorithms." ([source](https://en.wikipedia.org/wiki/Reverso_(language_tools)#History))
- 2016: "In 2016 Reverso acquired Fleex, a service for learning English via subtitled movies." ([source](https://en.wikipedia.org/wiki/Reverso_(language_tools)#History))
- 2018: "In 2018 it released a new mobile app, which combines translations and learning activities." ([source](https://en.wikipedia.org/wiki/Reverso_(language_tools)#History))
- 2018: "In February 2018 it was reported that some translations on the Reverso translation web site returned antisemitic results, such as "Much nicer" returning "Dachau was much nicer than Auschwitz"." ([source](https://en.wikipedia.org/wiki/Reverso_(language_tools)#History))
