# Handoff gaps

Generated by `node tools/handoff-scan.mjs --write` (the loop item `loop:handoffs`, docs/NEXT.md). Do not edit by hand.

One page's result opening another already filled in (lib/handoff.js, `verse_handoff`; or a link that carries the data). 103 page pairs are connected; 808 pairs share a type and are not. Each lap builds the top few and tests them end to end.

Score: the shared type's weight (names, music, numbers, date, event, color, palette, image, table, location 3; items, number, duration, url 2; text, code 1), doubled when the receiving page already reads its link, +1 when both pages declare their types.
