# Handoff gaps

Generated by `node tools/handoff-scan.mjs --write` (the loop item `loop:handoffs`, docs/NEXT.md). Do not edit by hand.

One page's result opening another already filled in (lib/handoff.js, `verse_handoff`; or a link that carries the data). 43 page pairs are connected; 494 pairs share a type and are not. Each lap builds the top few and tests them end to end.
