# The salvage shelf

Cleanup step 3 (owner, 2026-10-10: "clean everything up that exists and tie it all together"; "just because nothing uses it doesnt mean it cant be salvaged"). One line for every piece that nothing uses, or that an earlier framing left behind: what it is, what it could become, and a rough size of that work (S: a run, M: a few runs, L: a project). **Nothing here was deleted or moved; every path still works.** A piece leaves the shelf when it is wired in (say where) or merged into its living twin. A promising one goes onto `domains/void.frontier.md` as a target.

Checked 2026-10-11 against the code: "nothing uses it" means no other file in the repo names it.
