find the red X · draft · not published

Is there a red X? Answer as fast as you can: "yes" (or the J key) or "no" (or F). In some rounds the others are all green, so a red X jumps out at once. In others the others are green Xs and red Os, so you have to check them. Treisman and Gelade (1980) found that the first kind takes about the same time however many items there are, while the second gets slower with every item added, as if attention visits them one by one. This page measures how many milliseconds each extra item costs you in each kind of round. It needs colour vision for red and green, so it is not a fair test for everyone. Everything stays in this browser.
