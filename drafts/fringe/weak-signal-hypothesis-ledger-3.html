weigh the signals · draft · not published

A hunch ledger that does the arithmetic. Start from how often things like this happen at all (the base rate), and write down your gut chance too. Then add each weak signal as it comes, saying how much more likely you would see it if the hunch were true than if it were false. The page updates the chance by Bayes' rule. When the hunch resolves, it scores both the worked chance and your gut, so you can see which serves you better. This is arithmetic on your own guesses, not a prediction service. Everything stays in this browser.
