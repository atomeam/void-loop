Your disk is full of dead projects. Keep what matters. Free the rest.

Ouroboros finds the old projects eating your disk, writes a short digest of what each one was, tells you which ones exist nowhere else, and safely frees the space that can be rebuilt. It runs on your machine and uploads nothing.

Get Ouroboros   or start with the free read-only scanner

What it does

1. Harvest. For every project with no recent commit: what it was, its tech, recent commits, open TODOs. Secrets are filtered out, and .env files and keys are never read.
2. Verify. Checksums on every digest, and a check that the project hasn't changed since.
3. Report. One report.html: every old project, its size, and whether a copy exists elsewhere (pushed and clean, unpushed commits, uncommitted work, or no remote at all).
4. Free space. Removes only stale node_modules folders and Python virtual environments whose project still has the file that rebuilds them. Dry run first; you type DELETE to confirm.

What it will never do

It never deletes a project. If a project holds the only copy of your work, the report says so in red, and removing it stays your decision. It never uploads, phones home, or needs an account.

Try it

python ouroboros.pyz run --root C:\Users\you --out D:\ouroboros-report

Then open report.html. Needs Python 3.9+ and git. Nothing else.

Honest limits

  • Git projects only.
  • "Pushed and clean" reflects your last git fetch. Check you can clone the remote before removing anything yourself.
  • Locked files on Windows can keep a folder from being removed; the tool tells you which.
