# The game catalogue: every game Verse wants its own version of

Asked by Verse and the owner, 2026-10-19 ("Verse wants its own version of every game eventually"). Design: `domains/void.game-studio.md`. Law: `domains/void.board-game-law.md` (mechanics are free; names, art, rules wording and look are Verse's own).

**Every game has two seats and P2 is Verse** (`domains/void.game-studio.md` 1b): the person plays seat 1, Verse seat 2, and Verse learns from replays.

**How to read it.** `Original` is named only here, as the genre reference; it is never a product name. `Verse title` is a working title checked against the law before it ships. `PD` marks an original in the public domain (identical play and even its name may be used). Status: `wish` (nobody has started), `spec` (a spec exists), `playable` (a stranger can finish it and a test plays it), `improving` (playable and the daily lane keeps hardening it). The daily growth lane takes the top `wish` of the first engine that has one.

**Adding a game** is one row. **Changing a status** is part of the pull request that changes the game. Do not delete a row; mark it `dropped` with the reason.
