## Thesis (full fold)

### The problem

| Constraint | Fact shape |
| --- | --- |
| Ogallala role | ~**30%** of U.S. irrigation groundwater; supports ~**1/5** of U.S. ag output; ~**$35B** regional livestock/crop economy |
| Depletion | Western KS / TX Panhandle water-table drops **>200 ft** in hard-hit pockets; recharge is fossil → **mining**, not cycling |
| Well reality | Historic wells that ran ~**1100 gpm** now often ~**140 gpm** |
| Southern projections | Large southern stretches lose reliable irrigation capacity under current draw |
| Cattle | Feedlot / livestock are a huge regional draw on the same aquifer |
| Competing load | AI / data-center water + power stories add political heat on the same scarce commons |

### The gap

No single trusted local operator who: **audits** the farm's water/energy system → **designs** a cheaper-water plan that still pays → **fills USDA paperwork** (EQIP/CSP) → **stays for the first two seasons** of IWM ops. Hardware vendors sell gadgets. NRCS ranks practices. Nobody wraps audit + plan + cost-share packaging + year-one ops + monitoring as one farm-side product.

### Sell the package, not the gadget

| Step | What ships |
| --- | --- |
| **1. Water / energy audit** | Baseline draw, pump/pivot efficiency, scheduling waste, crop mix thirst |
| **2. Conservation plan** | Solvent plan: VRI, drip, sensors, scheduling, cover/no-till, less-thirsty crops — sized to cashflow, not brochure |
| **3. EQIP / CSP packaging** | Practice codes **441, 442, 449, 163**; ~**75%** cost-share typical, up to **~90%** beginning / underserved producers |
| **4. Implementation + year-one IWM** | Stay on farm through first seasons; make the plan work in dirt |
| **5. Recurring monitoring** | Subscription: sensors + scheduling discipline + measured savings proof |

**Savings shape:** **15–30%** water typical; drip often **30–40%** in trials. Precision irrigation market ~**$9B** global ~2026, ~**9%** CAGR (context, not a quote).
