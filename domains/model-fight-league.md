# Domain: Model Fight League (idea, not built)

**The thought:** each robot is driven by a different AI model, so each one fights differently. The fights are real, not
scripted: the same arena, the same rules, and the model's own choices decide the outcome. Fits the Blackglass Syndicate
picture (AI models as the robots; the K.O.T.S.-style underground league; the cartoon and toy line later).

**Why it could earn:**
- People already argue about which model is "best"; a fight is a benchmark anyone can watch and share.
- Each model's style is visible (cautious, aggressive, tricky), so fighters become characters people root for.
- Ways in: free matches on a-to-mind.com; paid entry to enter your own prompt/strategy as a fighter; sponsored or
  branded fighters; replays and clips; later the figures and the show carry the same roster.

**What Void already has toward it:** live AI models through Workers AI; a turn-based game with an AI opponent
(Connect 4 in `void-live-deploy/skills/make.js`); 3D objects that materialize; a router that knows which model answered.

**Open questions:** which arena first (turn-based board game is cheapest and fair; real-time is costlier); how to keep
model costs inside the earned budget (spend still waits on the confirm line); fairness (same time and token limits per
model); whether model makers' terms allow public head-to-head matches.

**Not decided:** nothing is built or promised. Next step if Adam picks it up: one arena, two free models, one public match page.
