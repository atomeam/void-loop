# 3D Void figures first

Start here. Search or ask, and a little 3D version of that thing pops up. It lives in the Void you already set up, as if that stage is its new reality. Perfect that. After it works, the same path designs any real-world product.

## How a figure behaves

- It appears small and detailed, on the stage, not as a page about the thing.
- It interacts with the Void that is already there. A chair is sat on. A cup is picked up. A clock, a note, a shape, another figure: used or noticed, not ignored.
- Characters stay on brand. A celeb moves and acts in a way you recognize. An original character keeps one personality. Furniture stays furniture. An animal acts like that animal.
- Whoever or whatever is on the stage keeps existing: walking, sitting, waiting, using objects. They do not reset when you ask for something else.
- They stay until sent away. Throw one off the screen with the mouse and it is gone. That is the dismiss.
- A later option changes size, pose, or a part. The print file updates. The file is the owner's.

The talking, loving, walking toy is this same figure once the stage life is real. It is not a separate first build.

## Perfected means all of these, on one ask

1. Ask in Void and a little 3D version appears on the stage.
2. Spin it. See the front, the back, and the detail.
3. It uses or reacts to at least one thing already on the stage.
4. It keeps existing while another figure is summoned.
5. Drag it off the screen with the mouse and it leaves.
6. Download a print file a normal printer can take (STL or 3MF).
7. The file does not depend on a server to stay valid.

A recognizable celeb on the stage is a reference for behavior. A sold print of a real person's likeness needs the right to that likeness. Original characters have no such gate.

## Order

Until 1 through 5 are true, do not open a new product track. 6 and 7 are the handoff from the stage to the real world. `toy-problems.md` waits on a figure that already lives on the stage.
