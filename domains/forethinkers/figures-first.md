# 3D Void figures first

Start here. A 3D Void figure is a cute, highly detailed miniature that Void designs. Ask, it appears, spin it, export a print file, own it. Perfect that path. After it works, the same path designs any real-world product: another figure, a joint, a toy that talks and moves, a wearable, a field part.

The talking, loving, walking toy stays the concept. It is not the first build. A figure that cannot be summoned and printed cannot grow a mind or a gait.

## Perfected means all of these, on one original character

1. Ask in Void and a figure appears on the stage. Not a Wikipedia page.
2. Spin it. See the front, the back, and the detail.
3. Download a print file a normal printer can take (STL or 3MF).
4. The character is original. No Woody, no Moxie, no Persuadatron, no Cupboard kid.
5. A second ask changes an option: size, pose, or a small part. The file updates.
6. The file is the owner's. It does not depend on a server to stay valid.

Until those six are true, do not open a new product track.

## What this unblocks

The figure path is the design engine. A later product is the same ask, a different body, the same export. The offline mind, the voice, and the gait attach to a figure that already exists as a file.
