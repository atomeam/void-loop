# The Void

A second brain. Pages, wiki links, graph, Inbox, and a monthly room that empties when you Seal.

This device holds the mind. No accounts.

- **Today** — daily note, capture, harvest of open tasks
- **Inbox** — the queue. Keep a line and it becomes a page
- **Pages** — wiki `[[links]]`, tags, Lost (unwritten)
- **Graph** — hubs, dashed ghosts, Reset
- **Room** — this month’s vessels. Seal keeps the pages

Wander cap: 32 lasting pages.
