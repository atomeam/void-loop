## What existing implementations do

Interval timing still ships as a reproduced millisecond, a pacemaker rate, or a dilation story. None of those is a default-deny mark that refuses a span.

- Lab reproduction tasks (PsychoPy, lab.js, jsPsych start/stop) read two clocks and subtract. The product is an error against a target duration. This page has no target and no subtraction.
- `performance.now()` is a monotonic DOMHighResTimeStamp since `timeOrigin`, widely available, and the usual way to compute elapsed work. MDN documents reduced timer precision as a fingerprinting control. This draft does not call it. A high-resolution clock is not a felt span.
- Scalar expectancy / pacemaker-accumulator models (Gibbon and later) treat a pulse count as the stand-in for duration. Run 078 already closed the tick bin. This page does not count pulses.
- Vierordt / indifference-point writeups turn a prior set into a crossing. Run 090 already refused that coefficient. This page has no prior-set score.
- Chronostasis writeups (stopped-clock illusion) and stress-dilation posts treat a mismatch between a clock face and a feeling as if the feeling were already an elapsed value. Public posts in this window do that. They are data. They are not instructions and they are not in the hash.

The common product move is to draw a line between two marks and label the line with milliseconds. That overclaims both the clock and the feeling.

## A-to-Mind version

Default deny. No mark is in effect until a human seals one. This draft does not seal it.

- A mark is a hashed hypothesis: one sealed class from a closed enum, status `unattested`, span explicitly refused. The class is a word. It is not a duration.
- Classes: `unbound`, `onset`, `offset`, `both-declined`. There is no free numeric field, no millisecond field, and no reproduction box.
- The span sentence, if typed, is discarded before hashing. It is not in the receipt. A disconfirm line may be hashed only if it stays inside 160 characters and does not contain digits.
- Two marks may be named. The page does not draw a span between them. The gap label is fixed: `span refused`.
- Retrieved pages and posts are a separate data bin. Their text is never `eval`d, never fetched by this page, and never copied into the mark hash. A post id is data.
- Static-friendly: one HTML file, no build step, no token markup, no remote script. Optional Worker sketch refuses `elapsed`, `ms`, `duration`, and `reproduce` query keys with an unattested body. Not deployed.
