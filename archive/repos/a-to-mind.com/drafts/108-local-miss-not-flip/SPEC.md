## One-line

A sealed miss class hashes to a flip-refusal id. The flip sentence and any crowd tally are discarded and are not in the hash. A miss mark is not a flip and not a shared canon.

## What current implementations do

Mandela-effect boards and quizzes collect a crowd answer, show a percentage, and often treat agreement as a timeline or reality change. Academic work treats the same pattern as a shared false memory: Prasad and Bainbridge (Psychological Science, 2022) reported consistent wrong recalls of specific icons despite mostly canonical visual experience; a 2024 Transparent Replications repeat and a 2026 PLOS Biology paper on shared event details under misinformation stay in that reconstructive frame. Public posts in this window do both: a high-engagement joke about Spy Kids ages, a rejection of that joke, a catalog claim with no body, and at least one post that offers an episode-title change as a timeline shift. Those are claims. None of them is a hash that refuses the flip sentence.

## Stricter Void version

- Default deny. The page has no poll, no vote store, no crowd percentage, and no quiz score.
- Miss class is a closed set: `logo-gap`, `line-gap`, `spelling-gap`, `date-gap`, `abstain`, `local-only`. No named icon, no image, no quoted line.
- Opt-in is the radio itself. It is not a memory grant and not a witness statement.
- Canonical string is `miss-not-flip|v1|<class>|flip-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Flip sentence is scratch. It is cleared on submit and is not in the hash.
- Crowd tally field does not exist. A number typed into the scratch box is still scratch.
- Disconfirm line is recorded as not hashed. It does not become a shared canon.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A miss class would fail this draft if a sealed human later attested a flip sentence that was stored in the hash. A logo-gap label would fail as a shared canon if a pre-registered source pair showed the same item both was and was not the public version at the cited time and that pair were sealed as a flip. This draft does not perform that test.
