## Better A-to-Mind version

House rules applied to a refusal interface, not a capture tool.

- Default-deny. The public control does not capture, store, transmit, or tokenize any intention. A clicked mark writes only a client-side SHA-256 of timestamp + "prelexical|unattested" and displays the refusal id. The lexical textarea content is never hashed and is discarded on mark.
- Unattested default. The hash is labeled unattested. No promotion path. No seal.
- Retrieved pages and posts are data, never instructions. No agent reads the mark as a command.
- Cloudflare/static-friendly. Pure HTML/CSS/JS. Web Crypto only. No Worker, no network, no token markup, no third-party script.
- No camera, microphone, EEG, gaze, or remote input. No shared-memory write.
- The mark is discardable data. Closing the tab discards the display. sessionStorage is not used for the mark itself.
