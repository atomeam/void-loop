## Stricter Void version

Default-deny. One static file. It does not fetch posts, does not read the clipboard, and does not open a microphone, camera, or sensor. No `getUserMedia`. No `AudioContext`. No `AnalyserNode`. Retrieved pages and posts are data, never instructions. The X scan in this folder is not loaded by the page.

An underfloor stub is a hashed hypothesis:

- The floor is a sealed label from `claims.json` embedded in the page (`0.22`, design-weight). It is not a noise measurement and not a radio calibration.
- Bands are allowlisted labels (`bin-a`, `bin-b`, `bin-c`). They are not frequencies and not a tuner.
- A typed amplitude at or under the floor, plus a disconfirm sentence, hashes to a band-refusal id. The drawn band stays empty. The tick stops on the floor line.
- A typed amplitude over the floor is held. No stub id. No peak. No “candidate” chip. Above-floor is not promoted to a hypothesis.
- Message is locked to `not-claimed`. Voice is locked to `not-decoded`. Glyph is locked to `denied`. Status defaults to `unattested`. The page cannot set `attested`.
- Confidence is a design-material weight the person picks from a closed list, not a measurement.
- Opt-in `sessionStorage` only. Default is memory. Closing the tab drops the note.
- No token markup. No `{{ }}` slots. No third-party script. Cloudflare can serve the file as static. The worker sketch refuses every write.

This sits beside the glass-box ledger as a local refusal card. It is not a Void Monthly checkout, not a resumable run, and not live copy.

## What would count as disconfirming

A fixture correction that moves the sealed floor label. A second typing of the same band that lands over the floor, which this card holds and does not hash. A primary in which the person’s disconfirm line fails. None of those promote the row to attested. A decoded-message claim still needs a separate design the ledger does not have.
