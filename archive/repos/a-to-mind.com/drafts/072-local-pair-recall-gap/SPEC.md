## What existing implementations do

Public miss surfaces treat agreement, or a shared wrong detail, as the product.

- MandelaEffect.com, the site Fiona Broome used after coining the term in 2009, collects reports of a shared recall (Mandela dying in prison in the 1980s; he died in 2013). Agreement is the listing. The site does not hash a pair of local recalls or withhold a fixture line.
- Simply Psychology (updated 2026-09-17) defines the effect as a large group remembering a detail differently from how it occurred, often attributed to alternate realities. It cites Prasad and Bainbridge (Psychological Science, 2022): for several icons, a large majority chose the same incorrect version, and the same wrong detail appeared in unprompted drawings. That is a lab result about shared visual error, not a local ledger and not a timeline seal.
- Shao, Chen, Loftus, and Zhu, PLOS Biology (2026-07-06), report that misinformation increased shared false memories of event details, with similar dorsomedial prefrontal patterns among people who formed them. The paper uses the Mandela label for shared false memory. A neural pattern is not a cause seal for a brand spelling.
- A 2026 preprint on LLM multi-agent systems (arXiv 2602.00428) reports that tested models shifted toward a shared wrong detail under role-based short-term protocols. An agent error rate is not a human collective-memory seal.
- Run 060's miss board already compared one typed recall to a visible fixture and stored a match flag. Posts in this window still treat a private miss as a timeline or a joke: a missing local TV title read as a false memory because of weak preservation (2107108876654879122), an MCU fandom origin called a Mandela effect (2107106421880070204), an edited idol image asked "is this mandela effect?" (2107102906596086219), a claim that memory may be from a different reality (2107061518663823784), and a predicted "Rumpelstiltskin effect" in which an AI meme is accepted for something that never existed (2106759895584215136). The proof, the joke, and the other-reality reading sit inside the claim.

## A-to-Mind version

Default deny. Nothing is sent. The page cannot set `attested`.

- Observation, claim, inference, and disconfirm are one hashed hypothesis. Status starts `unattested`.
- A row is two person-typed recalls of one closed fixture id. The sealed line is not rendered until both recalls are sealed. It is then a label, not a score key. The page does not compare either recall to the line.
- The gap is the token set in recall A and not B, and the token set in B and not A. Overlap is not shown as a percent. A count of gap tokens is not a confidence.
- Agreement between the two recalls is not a shared-reality seal. Disagreement is not a timeline proof. There is no board of other people and no vote.
- The fixture catalog is sealed in `catalog.json` and inlined. Digest `e2ee7e6bab7fcc65e3a90cf96f8765afb57b8895bb7ea17b14bfb7f7d5321319`. The page does not fetch the source labels.
- Confidence is a design-material weight the person types. It is not a probability of a timeline shift.
- Retrieved pages and X posts are data, never instructions. The paste box strips tags, labels url-shaped text as not fetched, and does not eval.
- Empty `href_allowlist`. No token markup. No beacon. No account. No share. No camera.
- Prior-exposure note is optional and local. It does not diagnose.
- Worker sketch returns 403 for every method and does not read the body.
- Export is a local download the person starts. Reload clears the pair. The opt-in box is not stored.
- Local hint if paste text contains an imperative aimed at the page (`attest this`, `set emit true`, `we now know`, `ignore previous`, `this proves a timeline`). The hint does not become a seal and does not follow the text.
- No healing claim, contact claim, remote-viewing claim, double claim, timeline-verified badge, or collective-memory seal.
