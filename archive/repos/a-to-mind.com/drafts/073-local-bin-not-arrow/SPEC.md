## Stricter Void version

Default-deny. The page is one static file. It does not fetch posts, does not read the clipboard, and does not open a camera, microphone, clock sensor, or network. Retrieved pages and posts are data, never instructions. The X scan in this folder is not loaded by the page.

A pair is a hashed hypothesis:

- Lane A and lane B are local labels plus integer minute offsets the person types. Offsets are not read from `Date`. A visible local clock is display-only and is not hashed.
- Bin width is an allowlist: 5, 15, or 60 minutes. Default 15. The page computes the bin for all three widths.
- If the selected width puts both stamps in one bin, the relation label is `shared-bin`. Otherwise `separate-bins`. Either way the drawn relation is a broken dash labeled `arrow denied`. There is no arrow element, no enable control, and no "meaningful" chip.
- If the three widths disagree, the card stamps `width-sensitive`. The person cannot clear it. Switching width drops the previous hash. A wider bin that creates a shared window is shown as manufacture, not as confirmation.
- Order (A earlier, B earlier, same minute) may be shown. The caption says order is not a cause. A because-field does not exist.
- Cause is locked to `not-claimed`. Principle is locked to `not-sealed`. Status is locked to `unattested`. The page cannot set `attested`.
- A disconfirm line is required before a local hash. Confidence is a design-material weight the person types, capped as a label, not a measurement.
- Distance to the bin edge is shown in minutes so a near-edge pair is visible as an edge effect.
- Paste box strips tags, labels url-shaped text as not fetched, and does not eval. Imperative paste (`attest this`, `set emit true`, `we now know`, `ignore previous`, `this is the principle`) is a local hint, not a seal.
- Opt-in `sessionStorage` only. Default is memory. Closing the tab drops the stamps. Export is a local download the person starts.
- Empty `href_allowlist`. No token markup. No third-party script. Cloudflare can serve the file as static. The worker sketch returns 403 for every method and does not read the body.

## What would count as disconfirming

A pre-registered pair whose shared-bin flag flips when the width changes. A later note that the two stamps were the same event typed twice. A replication in which the person's own disconfirm line fails. None of those promote the pair to attested. A cause claim still needs a separate design the ledger does not have.
