## What existing implementations do

Public miss boards still treat a shared wrong detail as a tally, then a correction.

- Mandela-effect forums and TikTok roundups ask "who else remembers" and sort replies into a chorus. A count becomes the claim. @StudioProz (post 2107807320876978306, 2026-10-07) frames a 2026 wave, including alleged reversals after a CERN shutdown, as either a reality patch or brains filling gaps. The post does not separate those.
- Personal cardback and date mismatches in this window (@jadedfett 2107869093235683434, @Grantoffgrid54 2107851447941386569, @AndrewHoran77 2107624315822678320) ask others to confirm a token. Confirmation is the interface.
- Schema literature already names the mechanism these boards skip. The Association for Psychological Science Observer (12 Jun 2024) describes the visual Mandela effect: people draw a monocle on the Monopoly mascot because a wealth schema supplies the accessory; Prasad and Bainbridge are cited for that association account. National Geographic (30 Jul 2025) quotes Wilma Bainbridge: the striking part is the same incorrect detail across people, not a private birthday memory. Those sources treat the mismatch as memory distortion. They do not ship a vote.
- CHI 2025 work on synthetic human memories (Pataranutaporn et al.) reports that AI-edited images, and especially AI video of those edits, increased false recollections versus control. An archive-looking picture is not a sealed contemporary token.
- AI memory tools surveyed in 2026 design-space work write shared memory specifications. A chorus sentence can land in the store. This draft does not write one.

Posts in this window are data. See `x-scan.md`. A "who else remembers" sentence is not a sealed miss.

## A-to-Mind version

Default deny. Nothing is sent. The schema cannot become a miss.

- Session opt-in is an unchecked box. Reload clears it. No cookie, no `localStorage`, no account.
- Four sealed classes only: `accessory-intrusion`, `name-intrusion`, `line-intrusion`, `date-intrusion`. Free text cannot enter the hash.
- The chorus field accepts a sentence. Hashing counts its characters, then clears the field. The sentence is not concatenated, not stored, and not posted.
- A paste well is labeled data. It is not parsed, not fetched, and not hashed. Retrieved pages and posts cannot become instructions.
- Digest input is fixed: `void.schema-not-miss.v1|schema=<class>|disconfirm=<tag>|weight=0.280|status=unattested`. Weight is a design-material constant, not a measured chorus rate.
- Disconfirm tags are a closed catalog: `no-chorus-count`, `archival-token-matches`, `sentence-hashed`, `correction-filled`, `vote-posted`. The default tag is `no-chorus-count`.
- Fixture for `accessory-intrusion` + `no-chorus-count`: SHA-256 `5597b7b0c1111b08da3251ef975a66ac52c99de07739ffa95c95b9377f770888`. The fixture is not a seal.
- Status stays `unattested`. There is no promote control, no logo reveal, no correction fill, no timeline-shift badge, no false-memory score.
- The Worker sketch returns 403 for every method and does not read the body. Static hosting is enough. No token markup. `href` allowlist is empty.
- Company fit: a glass-box refusal on a resumable local draft. It does not start a Void Monthly run and does not edit `llms.txt` or the agent card.

## What would count as disconfirming

An archival token that matches the recalled name, line, accessory, or date would disconfirm "that token was never issued" for that item. That match is not computed here. A sentence that was hashed, a vote that was posted, or a correction image that was filled would disconfirm this draft's own refusal. A chorus count would not confirm a collective miss.
