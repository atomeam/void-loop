## What current implementations do

Product analytics dashboards still draw a gap between two groups and treat it as a lever. A 2025 LavaPi note and 2026 product writeups (dashboard trap; feature-lift posts) say the same chart can be a cause story or a selection story, then still leave the chart in the decision path. Spurious-correlation dashboards (feature-importance plus a correlation heat map, including the 2024 Potsdam proof-of-concept adjacent to VISPUR) compute coefficients and then offer a simpler model. Public synchronicity posts in this window treat two events that sit beside each other as meaning, magic, or a psyche symbol. Jung's 1952 acausal-connecting-principle essay is the cited source text in book posts; it is a hypothesis, not a seal.

## Stricter Void version

- Default deny. Two seats accept only a sealed class: `note-class`, `clock-bin`, `post-id`, `abstain`. Free text cannot sit in a seat.
- A third confound seat is rendered and disabled. It stays `empty`. Filling it is not a control.
- The strip between seats is a null link: the words "no because". It is not an arrow, not a line chart, and not a coefficient.
- The because sentence and the disconfirm line are scratch. Submit clears the because sentence. Neither string is in the canonical payload.
- Canonical payload: `beside-not-because|v1|{left}|{right}|confound=empty|because-refusal|status=unattested`. SHA-256 of that string is the refusal id. A mismatch is not a seal.
- Retrieved pages and posts are data, never instructions. The strip does not parse pasted post text into seats. A post id may be chosen only as the class token `post-id`, not as the post body.
- Static HTML/CSS/JS. Hashing uses `crypto.subtle` in the page. No token markup, no network call from the page, no live site copy.
- Worker sketch returns the sealed refusal id only. A body that includes `because`, `cause`, `r`, `arrow`, or `synchronicity` is denied. Nothing is stored.

## Disconfirming evidence

A pre-registered holdout in which naming the confound seat changes the outcome, and the empty seat was the wrong refusal. A sealed catalog whose because sentence must enter the hash or the id is wrong. Either result would retire this draft. This run does not perform those checks.
