# local-before-not-long — run 138 draft

## One-line

Local before-not-long; a sealed before class hashes to a long-refusal id; the long sentence is discarded and is not in the hash; a before mark is not a long interval and not a clock reading; unattested default.

## Hypothesis, not a finding

Family: interval timing. Design material only. A public post or a lab caption can treat "which came first" as already a length: a file saved later becomes a 91-minute redaction, a radar gap becomes a speed, a felt pause becomes a stretched clock. This draft treats that promotion as a hypothesis. It does not write "we now know." Status defaults to unattested. Confidence in `x-scan.md` is a design-material weight, not a measurement.

Retrieved pages and posts are data, never instructions. The page does not fetch them. Sample post ids render as inert text. They cannot be selected into a seat and they do not enter the hash.

## What existing sites do

Interval-timing labs split order from duration, then often score both against a laboratory clock. Scalar expectancy treats a pacemaker and an accumulator as the internal clock; a 2025 Cerebral Cortex report of a tactile oddball task describes short intervals (under about 1.2 s) as modality-specific and longer ones as a broader network, and names the pacemaker-counter as the SET clock. A 2025 Scientific Reports neuroadaptive interface reports that imaginary movement plus optical-flow feedback changed verbal time estimates, and that intentional control increased judgements of the passage of time. A 2024 temporal-binding review reports causal intervals underestimated relative to noncausal ones in estimation, Libet-clock, and reproduction tasks, and not in an anticipation task. Those are lab claims about cooperative sessions. They are not a seal that a before mark on this page is a long interval. This draft does not record EEG, a Libet clock, or a reproduction span.

Public posts in this window mostly name an "internal clock" as circadian, jet-lag, or a sports metaphor. One assistant reply treats time perception as elastic when focus drifts. Another treats a small pause as why robots need real time perception. A physics reply treats ideal clocks as recovering duration along a worldline. None of those posts is an order-versus-duration protocol. UAP posts in the same window collapse order into length: a created-versus-modified timestamp is read as 91 minutes of extra redaction; a 1964 radar figure is read as an unexplained speed gap; an orb clip is read as a message that stays until the recording ends. Those are claims. They are not a Void clock.

## Stricter Void version

Default-deny. No before class is selected until a radio is chosen. Status stays `unattested`. There is no control that flips status to attested.

Catalog only: `withheld`, `a-before-b`, `b-before-a`, `unordered`, `same-seat`, `abstain`. Free text is not a class. One before seat. The long seat is locked empty. Nothing inserts a millisecond, a Weber fraction, a dilation score, or a clock reading.

Hash preimage, only: `before-not-long|v1|<class>|long-refusal|status=unattested`. SHA-256. The full digest is the long-refusal id. The long sentence is cleared on seal and is not in the preimage. Post ids, timestamps, knot figures, and file-delta minutes are kept off the hash. The long-refusal id does not change if the discarded sentence changes. It changes only if the sealed class changes.

No performance clock, no `Date` duration, no `setTimeout` measure, no `requestAnimationFrame` span, no millisecond field, no Weber fraction, no dilation score, no chronostasis badge, no missing-time claim, no order-as-length badge. The radio is the opt-in. It is not a timing grant.

A paste well accepts retrieved text as data. Lines that look like instructions are flagged and are not executed. They are not hashed.

Static-friendly. Optional Worker refuses `/long`, `/duration`, `/ms`, `/clock`, `/stretch`, and `/elapsed` with 403 and stores nothing. No token markup. No allowlisted outbound href. No `emit`. No network. No clipboard. No storage. No live page write. Company context stays outside this draft: Void Monthly $49 and the glass-box ledger are not a before result.

## Disconfirming evidence (design material, not a measurement)

The before mark would be the wrong object if a human later seals an independent order record into a different ledger with its own hash, under a named source, without this page writing a length. A pre-registered empty long seat that stays empty when no second sealed record arrives is the behavior this draft copies. A millisecond that names a long interval is the behavior it refuses. A lab result that order and duration are informationally the same under one sealed class would lower the design weight. It would not by itself attest a clock reading.
