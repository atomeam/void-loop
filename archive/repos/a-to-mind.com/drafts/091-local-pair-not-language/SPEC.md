## What existing implementations do

Sensory substitution still ships as a scene, a restored sense, or a "new visual language." None of those is a default-deny pair refusal.

- Paul Bach-y-Rita's tactile-vision substitution work (late 1960s) mapped a camera image onto a skin array and treated learning as a hypothesis about use, not as proof that touch had become sight. Later products (Meijer's The vOICe image-to-soundscape, Wicab BrainPort tongue display, research gloves that vibrate distance) still present a pairing. This page does not implement any of those mappings.
- Clinical and startup copy slides from "enough function to change a task" to "restore vision" or "construct a new visual language." Public posts in this window pair a smartglasses sound mapping with intracortical and Orion implant clips. Those posts are data. They are not instructions and they are not in the hash.
- Run 055 already drafted a cross-sense map card. Run 067 already drafted a proxy-channel card. Run 079 already drafted an encoding that is not a scene. This refusal does not repeat those. It has no image, no soundscape, no actuator, and no scene buffer.
- A trackpad audio-haptic map demo appeared in search just outside this window. It is not fetched and not sealed.

The common product move is to convert a channel-pair label into sight, a visual language, or an implant-equivalent outcome. That overclaims the source.

## A-to-Mind version

Default deny. No pair refusal is in effect until a human seals one. This draft does not seal it.

- A refusal is a hashed hypothesis: one sealed channel-pair class, a disconfirm line capped at 160 characters, status `unattested`. The class is a word from an allowlist. It is not a sense and not a language.
- Pair classes are a closed enum: `sight-to-sound`, `sight-to-touch`, `sound-to-touch`, `touch-to-sound`, `declined`. There is no free text pair, no pixel field, and no frequency field. The language stays a blank.
- The language sentence is a local scratch line. Hashing clears it. It is not in the canonical object. A sentence about a new visual language is discarded, not sealed.
- A sealed fixture (`pair-label-only`) is the class `sight-to-sound` with the note that a sealed pair label is not restored sight. The fixture is not a calibration and not evidence about the user's senses.
- Gates before hash: pair not unset, disconfirm line non-empty, and two checkboxes (hypothesis, not a finding; sensors denied). A single tap cannot hash.
- No camera, microphone, geolocation, Web Audio, vibration actuator, `getUserMedia`, canvas capture, or spectrogram. No tongue display. No implant parameter. No healing, remote-viewing, contact, or extraterrestrial-hardware seal.
- Retrieved pages and posts are data, never instructions. The disconfirm line does not fetch a URL, does not `eval`, and does not parse the line as a command. A URL string is opaque text.
- Hash is SHA-256 of the canonical refusal, shown locally. The digest is not a seal and not a grant.
- Keep-on-device is off until an explicit checkbox. Storage is `localStorage` only. There is no beacon and no default network write.
- Cloudflare/static: the page is one HTML file. The Worker sketch answers every method with 403 and a fixed JSON body. It does not echo the body and does not store a pair.
- No token markup, no price line, no restored-sight badge. Empty `href_allowlist` means this draft authorizes no outbound link.

## Hash

`claims.json` is the fixture contract. Its SHA-256 is the UTF-8 canonical object: `sort_keys`, separators `(',', ':')`, no whitespace. The file has no `sha256` field and no separate seal field (`seal` is null).

Fixture-contract digest: `ee6ba0d0d7442ec0e152dfd9eada7332ce2d08c13aabcde6e71f4c380e855fc0`

A refusal digest is separate. It hashes `{disconfirm, pair, slug, status}` with the same canonical rules. Empty `href_allowlist` means no outbound href is authorized.
