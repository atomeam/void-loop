# F-197 WebGPU Predictive Spectral Constellation

## Concept
Novel combination of a spectral resonance lattice (WebGPU preferred, Canvas2D fallback), a local predictive mind (attention + residual forecast in pure JS / Worker-ready), and a generative constellation of interactive, user-correctable DOM thought-nodes. Closed-loop feedback from node interaction deposits energy back into the lattice. Progressive WebXR.

## Architecture
- Single `index.html`
- Lattice diffusion on canvas
- Local mind state (weights, history, residual)
- Dynamic DOM node factory with drag/click
- CSS custom properties for chrome morph
- localStorage seal
- Optional WebXR session

## Expected Outcome
Interactive spatial field that grows a living constellation reflecting the mind's prediction of user seeds and pointer activity. User can refine nodes. Fully offline-runnable.

## Mechanics
seed/pointer → deposit → diffusion → sample → predictive mind → spawn/position/label nodes → user interaction → deposit feedback → CSS morph.

## Failure Modes
No Worker needed in this version (inline mind). XR unsupported falls back to flat. Low performance reduces node count.
