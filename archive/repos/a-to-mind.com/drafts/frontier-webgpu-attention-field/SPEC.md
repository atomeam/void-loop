# WebGPU Attention Field — Frontier Prototype

Runnable spatial / local-AI capability for The Void canvas.

Open `index.html` in a WebGPU-capable browser (Chrome/Edge 113+).

- Type a concept and click Spawn Query: an attractor appears.
- Move mouse to sculpt forces.
- Add Particle to introduce new labels.
- Particles with similar hash features cluster more strongly under the query.

Architecture and outcomes recorded in FEATURE_LEDGER.md under Frontier Engine Experiments.
