Status: unattested. Seal: false. Emit: false. Not a live page.

## Family

non-lexical intent capture. Last use was run 100 (`local-press-not-word`). Earlier slugs `local-gloss-withheld`, `local-empty-lexeme-slot`, and `local-nonlexical-intent-note` are not reused. Queue was empty, so this is a candidate only. No Used row.

## One-line

A sealed trace class hashes to a lexeme-refusal id. The lexeme sentence is discarded and is not in the hash. A trace is not a lexeme and not a decoded intention.

## What current implementations do

Silent-speech reviews describe interfaces that try to map articulation or cortical patterns onto text or audio when no sound is heard. A January 2026 Nature Sensors review treats on-body sensors as the current accuracy-versus-wear trade, and EEG as a noisy look at activity before articulation. A 2026 Nature Neuroscience report of an ECoG speech-and-gesture implant describes restricted-vocabulary avatar output, not an open lexicon. Public posts in this window repeat that shape: one builder diagram runs "thought" into a non-invasive BCI and then into "AI translates intent"; a neurotech note quotes 56 words per minute and a 125,000-word vocabulary and still says that is not mind reading; a commentary says imagined speech has no audible ground truth, so mime-then-imagine is used to bootstrap a decoder. An independent teaching text says a stirring comes before any word, then warns that naming it makes it another governor. A theatre listing sells "mind-reading" as a stage show. None of those is a hash that refuses the lexeme.

## Stricter Void version

- Default deny. The page has no word field, no decoder, no letter board, no rate, and no vocabulary size.
- Trace class is a closed catalog of six triples: `arc|unlabeled|held`, `break|unlabeled|held`, `loop|untimed|held`, `gap|below-name|held`, `abstain|abstain|abstain`, `local-only|unnamed|held`. Free text is not a class.
- Hold has no decode value. `held` is not a sample waiting to be named. `abstain` is not a pass.
- Name-floor is a label, not a lexicon. `below-name` does not become a word. `unnamed` is not a missing gloss.
- Opt-in is the three radios. It is not a microphone grant, a camera grant, or an implant.
- Canonical string is `trace-not-lexeme|v1|<contour>|<name-floor>|<hold>|lexeme-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Lexeme sentence is scratch. It is cleared on submit and is not in the hash.
- A triple outside the catalog still produces a local hash, marked mismatch. Mismatch is not a seal.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `localStorage`, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A trace class would fail this draft if a sealed human later attested a lexeme sentence that was stored in the hash. A below-name gap would fail as a decoded intention if a pre-registered decode test, with chain of custody for the sensor file, were sealed as a lexeme. This draft does not perform that test.
