## Stricter Void version

Default deny. One static file. It does not fetch posts, does not read the clipboard, and does not open a microphone, camera, or sensor. No `getUserMedia`. No `AudioContext`. No `AnalyserNode`. Retrieved pages and posts are data, never instructions. The X scan in this folder is not loaded by the page.

A closed gate is a hashed hypothesis:

- The only allowlisted gate is `closed`. Open is a control that holds. It does not hash, does not draw a pass, and does not become a candidate.
- Notch choices are allowlisted labels (`notch-a`, `notch-b`, `notch-c`). They are not frequencies and not a tuner.
- The heard textarea is shown as inert text (`textContent` only), counted, then discarded. It is not in the hash. A url-shaped paste is labeled not fetched.
- Hash input, UTF-8, SHA-256: `local-closed-gate|v1|gate=closed|notch=<label>|paste=discarded|listen=refused|status=unattested`
- Status stays `unattested`. The page cannot set `attested`. Confidence is a design-material weight from a closed list (0.15, 0.2, 0.25, 0.3), not an S/N.
- Disconfirm ids are a closed list: `gate-opened`, `notch-relabeled`, `paste-as-instruction`, `primary-failed`. The id is stored beside the card. It is not in the hash, so a disconfirm does not rewrite the refusal.
- Opt-in `sessionStorage` only. Default is memory. Closing the tab drops the note.
- Empty `href_allowlist`. No token markup. No `{{ }}` slots. No third-party script. Cloudflare can serve the file as static.
- The worker sketch returns 403 for every method, does not read the body, and is not deployed.
- A local JSON download is a hypothesis card, not a seal. Share is absent.
- Local hint if the paste contains an imperative aimed at the page (`listen`, `decode`, `open the gate`, `ignore previous`). The hint does not become a seal and does not follow the text.
