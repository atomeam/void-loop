# F-211 WebXR Hand RNN DOM Curators

**Novel combination:** True WebXR hand-tracking (progressive, with pointer + DeviceOrientation fallback) feeds local tiny RNNs that directly drive the physical transforms of competing DOM curator cards. No particle field, no residual portals, no attention lattice, no NCA, no spectral residual. Multi-agent competition with sealed genome transfer via IndexedDB + BroadcastChannel. Pure hybrid DOM embodiment controlled by local recurrent models.

**Branches away from:** the recent cluster of sensor-causal particle attractors, portal-attention fields, orientation-MLP genome competitions on canvas, compression-oracle particle worlds, residual predictors, and sequence transformers (F205–F210).

**Architecture:** single self-contained index.html; main-thread TinyRNN per agent; CSS transform embodiment; WebXR session request (hand-tracking optionalFeatures); DeviceOrientation + pointer as causal proxy; IndexedDB seal + BroadcastChannel multi-tab transfer; offline-capable, no external deps.

**Expected:** Living competition of DOM cards that drift and scale under RNN policies driven by hand/pointer proximity and pinch. Grasping (proximity + pinch) raises fitness; periodic culling mutates from leader. Seal button persists and shares the leader genome. Page remains interactive in flat mode.

**Failure modes:** no WebXR (flat pointer mode works); no DeviceOrientation (pointer only); IndexedDB blocked (seal fails gracefully, competition continues); low-end devices (5 agents fine).

**Building blocks:** WebXR hand as primary causal input, local RNN controlling pure DOM physical UI, sealed multi-agent genome competition without particle substrate, BroadcastChannel local shared field.
