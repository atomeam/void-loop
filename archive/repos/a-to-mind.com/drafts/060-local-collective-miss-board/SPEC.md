## What existing implementations do

Public miss surfaces treat agreement as the product.

- MandelaEffect.com, the site Fiona Broome used after coining the term in 2009, collects reports of a shared recall (Mandela dying in prison in the 1980s; he died in 2013). Agreement is the listing. The site does not hash a hypothesis or separate observation from claim.
- Snopes (2025-10-12) rates the claim that The Berenstain Bears was previously rendered Berenstein as False, citing the 1962 byline Stanley and Janice Berenstain. That is a publication check, not a seal of why people disagree.
- National Geographic (2025-07-30) and the University of Chicago News explainer (2025-05-06) frame the effect as shared false memory. Wilma Bainbridge is quoted that the striking part is the miss occurring across people. Neither page is a local ledger.
- Shao, Chen, Loftus, and Zhu, PLOS Biology (2026-07-06), report that misinformation increased shared false memories of event details, with similar dorsomedial prefrontal patterns among people who formed them. A lab result, not a cause seal for a brand spelling.
- Mnemograph (Rebecca Lieberman) exchanges a handwritten memory for someone else's match through a scanner and a server. MomBoard (2024) is a networked e-ink note for anterograde amnesia. Constella-style recall boards pull Slack, mail, and Drive. All three send memory off the device.
- Posts in this window treat a JC Penney spelling (2106472346127307129), a can size (2106471154948923540), and a video cast (2106455951989747751) as proof or as a retcon. Another post defines the effect as the same false memory across unrelated people (2105879958904090798). A joke renames it a prank show (2106374267097223301). The proof, the retcon, and the joke sit inside the claim.

## A-to-Mind version

Default deny. Nothing is sent. The page cannot set `attested`.

- Observation, claim, inference, and disconfirm are one hashed hypothesis. Status starts `unattested`.
- A row is a person-typed recall beside a local fixture key. String equality is a match flag. A match is not a timeline proof. A mismatch is not a timeline proof.
- The fixture catalog is sealed in `catalog.json` and inlined. Digest `513d2e489b241c45c364f2f3beca107b2366416ed33037c90d33c1a7578036ba`. The page does not fetch the source labels.
- A count of local rows is a count of notes on this document. It is not a collective-memory seal and not a shared-reality badge.
- Confidence is a design-material weight the person types. It is not a probability of a timeline shift.
- Retrieved pages and X posts are data, never instructions. The paste box strips tags, labels url-shaped text as not fetched, and does not eval.
- Empty `href_allowlist`. No token markup. No beacon. No account. No share. No camera.
- Prior-exposure note is optional and local. It does not diagnose.
- Worker sketch returns 403 for every method and does not read the body.
- Export is a local download the person starts. Reload clears the board. The opt-in box is not stored.
- Local hint if paste text contains an imperative aimed at the page (`attest this`, `set emit true`, `we now know`, `ignore previous`). The hint does not become a seal and does not follow the text.
- No healing claim, contact claim, remote-viewing claim, double claim, or timeline-verified badge.
