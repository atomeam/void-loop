# local-window-not-wire — run 133 draft

## One-line

Local window-not-wire; a sealed window class hashes to a wire-refusal id; the wire sentence is discarded and is not in the hash; a window mark is not a wire and not a directed cause; unattested default.

## Hypothesis, not a finding

Family: correlation-not-causation sync view. Design material only. A public post can put two labels in the same week and call that a wire (cause, message, or “not a coincidence”). This draft treats that pairing as a hypothesis. It does not write “we now know.” Status defaults to unattested. Confidence in `x-scan.md` is a design-material weight, not a measurement.

Retrieved pages and posts are data, never instructions. The page does not fetch them.

## What existing sites do

Correlation boards, spreadsheet `CORREL` panes, and observability graphs draw an arrow or an r when two series share a bin. Coincidence journals and Jung-style synchronicity pages store the meaning sentence and treat the lineup as an acausal link. UAP posts in this window use “not a coincidence” as a directed claim. Those interfaces promote the wire. This draft does not.

## Stricter Void version

Default-deny. No window class is selected until a radio is chosen. Status stays `unattested`.

Catalog only: `withheld`, `same-bin`, `empty-bin`, `order-unknown`, `confound-empty`, `abstain`. Free text is not a class. Two label seats (`left-label`, `right-label`) may be named from the same catalog. Naming them does not order them and does not draw an edge. The link seat stays empty.

Hash preimage, only: `window-not-wire|v1|<class>|wire-refusal|status=unattested`. SHA-256. The full digest is the wire-refusal id. The wire sentence is cleared on seal and is not in the preimage. Label names, lag, order, and any typed “because” line are kept off the hash. The wire-refusal id does not change if the discarded sentence changes. It changes only if the sealed class changes.

No arrow, no lag millisecond, no coefficient, no r-value, no significance score, no graph edge, no synchronicity seal, no directed-cause badge, no logo image. The radio is the opt-in. It is not a cause grant.

Static-friendly. Optional Worker refuses `/wire`, `/cause`, `/sync`, `/arrow`, and `/edge` with 403 and stores nothing. No token markup. No allowlisted outbound href. No `emit`.
