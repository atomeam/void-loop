# F-044 Resonant Echo Portals

Self-contained interactive prototype for The Void canvas.

- Canvas2D Gray-Scott lattice (120x80)
- Web Worker evolutionary mind optimizing feed/kill for gesture resonance
- Draggable DOM portals that emerge at high activity and relocate seeds
- Page chrome (hue, coherence badge) morphs with energy and fitness
- Seal button persists genome to localStorage

Open index.html in a browser. Drag to seed, interact with portals, seal when the mind finds resonance.
