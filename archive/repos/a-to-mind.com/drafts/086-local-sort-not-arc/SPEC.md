## Stricter Void version

Default deny. No row until both classes match `YYYY-MM` and the later class sorts after the earlier class. The page does not swap them. A reversed pair is a refusal, not an inferred arc.

The narrative textarea is shown as inert text (`textContent` only) and then discarded. It is not in the hash. Pasted pages and posts are data, never instructions. No fetch. Empty href allowlist. No token markup.

`local-sort-not-arc|v1|earlier=YYYY-MM|later=YYYY-MM|narrative=discarded|arc=refused|status=unattested`
