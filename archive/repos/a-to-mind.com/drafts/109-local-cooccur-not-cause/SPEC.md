## One-line

A sealed pair class hashes to a cause-refusal id. The cause sentence and any meaning gloss are discarded and are not in the hash. A co-occurrence mark is not a cause and not a synchronicity.

## What current implementations do

Synchronicity journals treat two noticed events as a sign. Synchronicity Tracker (App Store listing, 2026) runs a seven-question weight and a 1–10 significance score, then a constellation timeline and optional correlation unlock. Synchronicity Journal (Kickstarter prototype page) logs dreams, repeating numbers, and events and asks the app to uncover hidden connections. Public posts in this window quote Bernard Beitman’s definition of a meaningful coincidence as a mental event beside an external event, assert that synchronicity-induced psychosis is real, and ask whether thousands of similar archetypal signals are more than coincidence. Those are claims. None of them is a hash that refuses the cause sentence.

## Stricter Void version

- Default deny. The page has no arrow, no coefficient, no r-value, no significance score, and no constellation.
- Pair class is a closed catalog of six triples: `thought|number|same-day`, `thought|name|same-hour`, `number|symbol|same-day`, `name|symbol|untimed`, `abstain|abstain|abstain`, `local-only|local-only|untimed`. Free text is not a class.
- Same-class pairs other than the two abstain/local-only rows are not a co-occurrence. They do not enter the catalog.
- Opt-in is the two slot radios plus the window radio. It is not a witness statement and not a meaning grant.
- Canonical string is `cooccur-not-cause|v1|<left>|<right>|<window>|cause-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Cause sentence and meaning gloss are scratch. Both are cleared on submit and are not in the hash.
- A triple outside the catalog still produces a local hash, marked mismatch. Mismatch is not a seal.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A pair class would fail this draft if a sealed human later attested a cause sentence that was stored in the hash. A thought|number row would fail as a synchronicity if a pre-registered base-rate test showed the pair above chance and that test were sealed as a cause. This draft does not perform that test.
