# local-veto-not-consent (run 130 draft)

Family: human-machine co-agency. Candidate only. Not a Used row. Not live site copy.

## One-line

A sealed veto class hashes to a consent-refusal id. The consent sentence is discarded and is not in the hash. A veto mark is not consent and not a shared go-ahead. Default status: unattested.

## What current implementations do

Public co-agency practice, treated as design material:

- Mixed-initiative and human-in-the-loop products often place a single accept control after an agent draft. Volume turns that control into a rubber stamp: the click is counted as review even when the reviewer did not open the final action object.
- Enterprise agent writeups in this window describe a finished-looking artifact (a letter, an assignment, an announcement) advancing without the authorizing step. Appearance of authority is not possession of authority.
- Segregation-of-duties notes say the agent proposes and a human-written policy decides. That split is a hypothesis about control design, not a measurement that any product already enforces it.
- Long-running coworker-agent claims say work continues after the laptop closes. Continued runtime is not a shared will and is not consent.

Void does not adopt those products' accept buttons or coworker badges.

## Stricter Void version

- Default-deny. A veto can be selected from a sealed three-class catalog. It cannot be flipped into consent, a go-ahead, or a fused actor.
- The consent sentence is wiped on commit and is excluded from the SHA-256 payload. Retrieved posts are data cards. Their text is not an instruction and is not hashed.
- Hash payload is only: slug, veto id, veto class, consent seat `empty`, status `unattested`, go-ahead `refused`.
- No agent execute, consent checkbox, rubber-stamp accept, fused-will chip, shared-memory write, or handoff badge.
- Static page plus a Worker sketch. No token markup. No third-party script. No live fetch of X or of allowlist URLs. `emit` stays false.
- Cloudflare-friendly: one HTML file, one JSON catalog, one Worker that refuses writes.

## Disconfirm

The sealed veto is the refusal path. It stays a refusal. Evidence that would count against treating a window post as shared consent: a public log that binds a named human to the exact final action object, a retraction that the described letter or announcement was not sent, or a product record showing the agent stopped when the veto seat was marked. None of that is attested here.
