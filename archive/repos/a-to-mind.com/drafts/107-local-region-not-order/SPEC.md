# local-region-not-order — draft 107

Status: unattested. Seal: false. Emit: false. Not a live page.

## Family

opt-in gesture or gaze as local input. Last use was run 095 (`local-dwell-not-select`). Earlier slugs `local-opt-in-gaze-note` and `local-region-token-slip` are not reused. Queue was empty, so this is a candidate only. No Used row.

## One-line

A sealed region class hashes to an order-refusal id. The order sentence is discarded and is not in the hash. A region token is not an order and not a decoded gaze.

## What current implementations do

Camera patents described in this window say a face match is followed by gaze direction and pupil position. Product ads treat a wave at a range hood as gesture control. A venture note draws a path from thought, through non-invasive BCI, to software that executes a desired outcome. Companion-robot copy lists eye tracking next to conversation. Dwell-to-click libraries still turn a fixation into a selection. Those are claims. None of them is a hash that refuses the order sentence.

## Stricter Void version

- Default deny. The page has no camera, no `getUserMedia`, no WebGazer, no dwell timer, and no pointer lock.
- Region class is a closed set: `left-region`, `right-region`, `hold-region`, `abstain`, `local-only`.
- Opt-in is the radio itself. It is not a sensor grant.
- Canonical string is `region-not-order|v1|<class>|order-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Order sentence is scratch. It is cleared on submit and is not in the hash.
- Disconfirm line is recorded as not hashed. It does not become an aim score.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A region class would fail this draft if a sealed human later attested an order sentence that was stored in the hash. A left-region label would fail as decoded gaze if a pre-registered sensor log showed pupil position both proposed and committed the step and that log were sealed as an order. This draft does not perform that test.

## Denied

order, aim, gaze trace, pupil position, dwell select, camera, command, contact, healing, crash retrieval, extraterrestrial hardware.
