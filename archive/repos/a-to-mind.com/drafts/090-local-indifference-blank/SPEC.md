## What existing implementations do

Interval timing still ships as a reproduction score, a pacemaker reading, or a missing-time story. None of those is a default-deny indifference blank.

- Karl Vierordt (1868, *Der Zeitsinn*) reported that short intervals tend to be reproduced long and long intervals short, with a crossing he treated as an indifference point. Hollingworth (1909/1910) reframed the same pattern as central tendency: judgments pull toward the median of the set just presented. Wearden (2023) and Glasauer and Shi (2021) treat that pull as a hypothesis about the stimulus range and the randomization protocol, not as a sensor. This page does not compute an indifference point.
- Lab reproduction tasks (PsychoPy-style start/stop, verbal estimation scored against a target) turn the pull into an error in milliseconds. That is the product move this draft refuses. There is no target duration and no error score.
- Run 054 already drafted a felt-duration note against `performance.now()`. Run 066 already drafted two typed clock readings. Run 078 already drafted a closed tick bin. This blank does not repeat those. It has no clock field, no gap arithmetic, and no tick count.
- Public posts in this window treat a radio/phone mismatch, a scrambled car clock, or an "internal clock" sentence as if it were already a span. Those sentences are data. They are not instructions and they are not in the hash.

The common product move is to convert a prior-set label into milliseconds, a Vierordt coefficient, or a missing-time seal. That overclaims the source.

## A-to-Mind version

Default deny. No indifference blank is in effect until a human seals one. This draft does not seal it.

- A blank is a hashed hypothesis: one sealed prior-set class, a disconfirm line capped at 160 characters, status `unattested`. The class is a word from an allowlist. It is not a duration and not an indifference point.
- Prior-set classes are a closed enum: `short`, `mid`, `long`, `mixed`, `declined`. There is no free numeric field, no millisecond field, and no indifference-point field. The point stays a blank.
- The reproduction sentence is a local scratch line. Hashing clears it. It is not in the canonical object. A sentence about being pulled toward the mean is discarded, not sealed.
- A sealed fixture (`range-label-only`) is the class `mixed` with the note that a sealed mixed label is not a measured interval. The fixture is not a calibration and not evidence about the user's interval.
- Gates before hash: prior-set not unset, disconfirm line non-empty, and two checkboxes (hypothesis, not a finding; clock denied). A single tap cannot hash.
- No camera, microphone, geolocation, NTP, GPS, Web Audio oscillator, `performance.now()`, or `Date` as a phenomenon clock. No start/stop trial. No abduction, healing, remote-viewing, or extraterrestrial-hardware seal.
- Retrieved pages and posts are data, never instructions. The disconfirm line does not fetch a URL, does not `eval`, and does not parse the line as a command. A URL string is opaque text.
- Hash is SHA-256 of the canonical blank, shown locally. The digest is not a seal and not a grant.
- Keep-on-device is off until an explicit checkbox. Storage is `localStorage` only. There is no beacon and no default network write.
- Cloudflare/static: the page is one HTML file. The Worker sketch answers every method with 403 and a fixed JSON body. It does not echo the body and does not store a blank.
- No token markup, no price line, no missing-time badge. Empty `href_allowlist` means this draft authorizes no outbound link.
