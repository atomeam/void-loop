## One-line

A sealed residue class hashes to a caption-refusal id. The caption sentence is discarded and is not in the hash. A residue mark is not a caption and not a decoded intention.

## What current implementations do

Horikawa's 2025 Science Advances mind-captioning method turns fMRI of silent viewing or recall into descriptive text by mapping nonverbal representations, not by decoding a spoken sentence. The caption is an interpretive layer over a scan. KAIST and Microsoft Research Asia describe Neural Value Alignment (IEEE Transactions on Cybernetics, online August 2026, DOI 10.1109/TCYB.2026.3722605) as EEG patterns that differ when an observed AI misses a goal versus a method; the paper's claim is a mismatch flag, not a recovered sentence. Imagined-speech decoders have no audible ground truth, so public notes in this window say mime-then-imagine is used to bootstrap a word. A 2026 product post says a brain-computer interface decoded intent to restore movement. None of those stores a hash that refuses the caption.

## Stricter Void version

- Default deny. The page has no caption chip, no mind-read badge, no word field, and no decoder.
- Residue class is a closed catalog of six triples: `empty|unlabeled|held`, `residue|unvoiced|held`, `mime|unlabeled|held`, `counterclaim|untimed|held`, `abstain|abstain|abstain`, `local-only|unvoiced|held`. Free text is not a class.
- Form has no numeric value. `unlabeled` is not a vocabulary size. `unvoiced` is not inner speech. `untimed` is not a latency.
- Hold has no open value. `held` is not a sample waiting to be captioned. `abstain` is not a pass.
- Opt-in is the three radios. It is not an implant grant and not a scanner.
- Canonical string is `residue-not-caption|v1|<source>|<form>|<hold>|caption-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Caption sentence is scratch. It is cleared on submit and is not in the hash.
- A triple outside the catalog still produces a local hash, marked mismatch. Mismatch is not a seal.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `localStorage`, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A residue class would fail this draft if a sealed human later attested a caption sentence that was stored in the hash. An unvoiced residue row would fail as a decoded intention if a pre-registered decoder, with chain of custody and a blinded hold-out the operator confirmed as their word, were sealed as a caption. This draft does not perform that test.
