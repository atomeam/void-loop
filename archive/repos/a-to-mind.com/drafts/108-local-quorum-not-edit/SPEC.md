## One-line

A sealed quorum class hashes to an edit-refusal id. The edit sentence is discarded and is not in the hash. A quorum mark is not an edit and not a residue of another record.

## What current implementations do

Public Mandela-effect boards treat a shared miss as residue: a logo, a line, a spelling, or a date that "used to be" otherwise. A 2026 write-up of the same lists cites a 2022 YouGov item set and the Deese-Roediger-McDermott false-recall procedure as ordinary shared error, not as a world edit. Edelson et al. (Science, 2011) reported that people often adopted a group's wrong recollection even after a correct first answer; that paper is a memory-conformity result, not a timeline result. A July 2026 PLOS Biology paper reports shared false details after misinformation and calls that pattern evidence for the Mandela effect as a memory phenomenon. Window posts still ask whether agreement is a parallel record, a CERN patch, or a brain fill-in. Those are claims. None of them is a hash that refuses the edit sentence.

## Stricter Void version

- Default deny. The page has no tally store, no vote count, no residue field, and no timeline selector.
- Quorum class is a closed set: `logo-miss`, `line-miss`, `spelling-miss`, `date-miss`, `abstain`.
- Opt-in is the radio itself. It is not a crowd grant and not a count.
- Canonical string is `quorum-not-edit|v1|<class>|edit-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Edit sentence is scratch. It is cleared on submit and is not in the hash.
- Disconfirm line is recorded as not hashed. It does not become a residue score.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A quorum class would fail this draft if a sealed human later attested an edit sentence that was stored in the hash. A logo-miss label would fail as a residue if a pre-registered primary artifact, dated before the claimed edit and sealed as the prior record, both matched the miss and were absent from every contemporaneous copy. This draft does not perform that test. Agreement count is not that artifact.

## Denied
