## One-line

A sealed repeat class hashes to a weight-refusal id. The weight sentence and the tally are discarded and are not in the hash. A repeat mark is not a weight and not a detection.

## What current implementations do

Radio SETI candidate pipelines (Breakthrough Listen style cuts, FAST narrowband screens) keep a survivor only after ON/OFF, neighbor-beam, polarization, and multi-site checks. A second look that fails is treated as interference; a second look that holds is still not a detection. Public writeups of K2-155 (October 2026) left one narrowband event unexplained and then favored terrestrial or instrumental interference because the feature was strong in one polarization and similar features appeared toward other stars. Exoplanet validation posts in this window treat a TESS-only false-positive probability of 3–14% as below the bar for statistical validation. Social UAP posts treat repetition — another sphere clip, another secrecy anecdote — as if the count itself were a weight.

## Stricter Void version

- Default deny. The page has no receiver, no URL fetch, and no promotion control.
- Repeat class is a closed set: `sky-follow`, `site-split`, `polarization-split`, `neighbor-beam`, `non-repeat`.
- Canonical string is `repeat-not-weight|v1|<class>|weight-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Weight sentence and tally are scratch. They are cleared on submit and are not in the hash.
- Disconfirm line is recorded as not hashed. It does not update a prior.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A repeat class would fail this draft if a sealed human later attested a numeric weight that was computed from the tally and stored in the hash. A sky-follow label would fail as a detection if a separated site and a neighbor beam both reproduced the event under a pre-registered cut and that reproduction were sealed as a detection. This draft does not perform that test.
