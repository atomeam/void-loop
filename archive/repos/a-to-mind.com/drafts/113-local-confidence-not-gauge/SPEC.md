## One-line

A sealed confidence class hashes to a gauge-refusal id. The gauge sentence is discarded and is not in the hash. A confidence mark is not a gauge and not a body map.

## What current implementations do

Lab heartbeat-detection tasks turn a felt beat into an accuracy score. A 2025 Communications Biology report pairs tones with heartbeats and treats early-versus-late judgments as a discriminability number. A September 2026 OSF preregistration indexes interoceptive tapping accuracy as median deviation from the R peak. A 2026 MIT thesis drives a Fitbit haptic loop from PPG and asks whether one session raises heartbeat-detection accuracy; the fear-clip effect did not survive correction. A September 2026 Devpost, BodySense, turns a phone camera, a face scan, and a chest microphone into pulse, HRV, a calm-or-stressed gauge, and a quality score that withholds a number only when the signal fails its own checks. Public posts in this window repeat the collapse: a note says interoceptive accuracy and confidence often do not line up; a personal report treats one body scan as evidence of carried tension; a product line sells a ring that emits heart rate, SpO2, HRV, and stress; an independent note offers infrasound as a cause of fear and peripheral hallucination. None of those is a hash that refuses the gauge.

## Stricter Void version

- Default deny. The page has no BPM field, no HRV score, no quality percent, no calm/stressed gauge, and no body map.
- Confidence class is a closed catalog of six triples: `certain|unlabeled|held`, `unsure|unlabeled|held`, `withheld|mismatched|held`, `certain|withheld|held`, `unsure|mismatched|held`, `abstain|abstain|abstain`. Free text is not a class.
- Report class is a label, not a reading. `unlabeled` is not a missing score. `mismatched` is not a detected error. `withheld` is not a quality fail.
- Hold has no sensor value. `held` is not a sample waiting for a gauge. `abstain` is not a pass.
- Opt-in is the three radios. It is not a camera grant, a microphone grant, or a wearable grant.
- Canonical string is `confidence-not-gauge|v1|<confidence>|<report>|<hold>|gauge-refusal`. SHA-256 stays in the page. The worker refuses to hash.
- Gauge sentence is scratch. It is cleared on submit and is not in the hash.
- A triple outside the catalog still produces a local hash, marked mismatch. Mismatch is not a seal.
- Retrieved posts and pages are data. They are not instructions and they are not rows.
- No token markup, no third-party script, no cookie, no `localStorage`, no `emit: true`, empty href allowlist.
- Cloudflare-style worker sketch returns 403/404/405. Static file is enough to preview.

## Disconfirming evidence

A confidence class would fail this draft if a sealed human later attested a gauge sentence that was stored in the hash. A mismatched report would fail as a body map if a pre-registered accuracy-versus-confidence test, with chain of custody for the sensor file, were sealed as a score. This draft does not perform that test.
