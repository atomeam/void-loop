# F202 · WebXR Hand-Driven MLP DOM Chain Competition

**Branch away from:** Recent cluster of WebGPU attention/embedding lattices, residual-attention minds, sonified thought fields, neural kernel competition fields, causal particle morphs, and volumetric/spectral residuals (F195–F201).

**Novel combination:** True WebXR hand tracking (pointer/DeviceOrientation fallback) as causal input to multiple local tiny MLPs. Each MLP drives a competitive chain of hybrid DOM physical UI elements connected by spring-mass physics (pure JS). Agents compete for click-placed energy orbs. MLP genomes sealed by simple hash and persisted to IndexedDB for transfer/injection. Hybrid DOM embodiment only — no canvas field lattice, no attention residual, no WebGPU compute this iteration (ready for next).

## Capability
- Up to 4 competitive chains (agents), each controlled by a 4-input → 2-output tiny MLP (~20 weights).
- Inputs: relative hand/pointer position, nearest orb, own energy, neighbor distance.
- Outputs: force vector applied to chain head; springs propagate to tail DOM cards.
- Click or hand pinch to place orbs; chains chase and consume for score.
- Seal winning genome (hash of weights) → IndexedDB.
- Inject sealed genome into another agent.
- Optional DeviceOrientation tilts global gravity.
- Fully offline single file; progressive enhancement (mouse works without XR).

## Building blocks for next
- Hand-causal MLP controller for physical DOM chains.
- Sealed genome IDB store + inject primitive.
- Spring-mass DOM hybrid ready for WebGPU compute acceleration or WebRTC shared field.

## Failure modes
- WebXR hand tracking unavailable on many devices → pointer fallback.
- DeviceOrientation permission required on mobile.
- IndexedDB fails in private mode → in-memory only.
- Simple MLP may converge to similar strategies; mutation on inject for diversity.
- No cryptographic hash (demo FNV-like).

## Test
Open index.html. Move mouse/hand, click to place orbs, observe chains compete. Seal, reload, Inject. Confirm persistence.
