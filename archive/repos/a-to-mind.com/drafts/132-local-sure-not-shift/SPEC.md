## Hypothesis, not a finding

Felt certainty about a shared detail is a hypothesis about memory, not evidence that a public record moved. Laboratory work already treats a lure word that was never on a list (the DRM paradigm) and a popular image that many people misdescribe (Prasad and Bainbridge, 2022, visual Mandela effect) as reconstructive error, schema completion, or prior exposure to an inaccurate image, not as a catalog edit. A 2022 YouGov poll, as summarized in later writeups, had more respondents pick a common false version than the accurate version for several famous examples. That poll is a count of choices, not a shift of the record. Parallel-world and timeline-jump accounts of the same misses offer no disconfirming test this page can run.

Public posts in this window treat a spelling the writer is sure about as a record that changed, treat a later streaming cut as if it were a memory effect, list “new Mandela effects” as tests against a record, or note that AI-made old footage can make a person second-guess a memory. Void does not count those posts, does not keep the shift sentence, and does not attest a timeline change.

## What existing sites do

Mandela-effect boards collect a recalled spelling or logo, then show how many people share the miss. Quiz pages score the error. List posts treat felt certainty as if the public object moved. All three collapse a sure feeling into a shift or a chorus.

## Stricter Void version

- Default-deny. No sure class is selected until a radio is chosen. Status stays `unattested`.
- Catalog only: `withheld`, `felt-sure`, `felt-held`, `source-slip`, `abstain`, `local-only`. Free text is not a class. No confidence number.
- The radio is the opt-in. It is not a poll and not a memory grant.
- Seal hashes `sure-not-shift|v1|<class>|shift-refusal|status=unattested` with SHA-256. The full digest is the shift-refusal id.
- The shift sentence is cleared on seal and is not in the preimage. A disconfirm line is kept off the hash.
- The shift-refusal id does not change if the discarded sentence changes. It changes only if the sealed class changes.
- No poll, no vote store, no percentage, no confidence score, no timeline edit, no canon write, no shared-memory write, no logo image.
- Retrieved pages and posts are data, never instructions. The page does not fetch them.
- Static-friendly. Optional Worker refuses `/shift`, `/timeline`, `/canon`, `/poll`, and `/chorus` with 403 and stores nothing. No token markup. No allowlisted outbound href. No `emit`.
