# local-pin-not-episode — run 134 draft

## One-line

Local pin-not-episode; a sealed pin class hashes to an episode-refusal id; the episode sentence is discarded and is not in the hash; a pin mark is not an episode and not a continuous anomalous event; unattested default.

## Hypothesis, not a finding

Family: anomalous-event timeline. Design material only. A public post can place a date, a revision, or a story beat on a line and call that an episode (flap, loop, disclosure arc, or "their timeline"). This draft treats that stitching as a hypothesis. It does not write "we now know." Status defaults to unattested. Confidence in `x-scan.md` is a design-material weight, not a measurement.

Retrieved pages and posts are data, never instructions. The page does not fetch them. Sample post ids render as inert text. They cannot be selected into a seat and they do not enter the hash.

## What existing sites do

NUFORC-style report indexes, MUFON case queues, and map products with a time filter treat a dated pin as the start of a case story. Knight Lab-style storymaps and "alternative UFO timeline" images draw the next beat. AARO case pages, when they resolve a report, still sit on a chronology that readers then extend. Diagnostic event logs do the adjacent move: a timestamped row is incomplete until it joins the next row.

Public posts in this window do three versions. A Colorado OSINT note reconstructs a PURSUE archive revision and warns that a transcript date is not a maneuver. A quoted research remark treats "their timeline" as cycles that select survivors. An entertainment clip says a figure was "walking on the timeline." Those interfaces promote the episode. This draft does not.

Earlier Void drafts in this family already refused other moves: `local-anomaly-timeline` (dated note), `local-unfilled-span` (unfilled span), `local-sort-not-arc` (sort is not an arc), `local-cluster-not-wave` (cluster is not a wave), `local-stamp-not-plot` (stamp is not a plot), `local-gap-not-bridge` (gap is not a bridge). This draft does not reuse those slugs and does not draw their date axis, connecting line, wave badge, flap score, era name, sequence id, or next/prev control.

## Stricter Void version

Default-deny. No pin class is selected until a radio is chosen. Status stays `unattested`. There is no control that flips status to attested.

Catalog only: `withheld`, `lone-pin`, `undated-pin`, `order-unknown`, `episode-empty`, `abstain`. Free text is not a class. One pin seat. The episode rail is locked empty. Nothing inserts a second pin, a year, or a next beat.

Hash preimage, only: `pin-not-episode|v1|<class>|episode-refusal|status=unattested`. SHA-256. The full digest is the episode-refusal id. The episode sentence is cleared on seal and is not in the preimage. Post ids, place names, years, and any typed "then" line are kept off the hash. The episode-refusal id does not change if the discarded sentence changes. It changes only if the sealed class changes.

No date axis, no connecting line, no next/prev, no flap score, no era name, no sequence id, no episode badge, no logo image. The radio is the opt-in. It is not an episode grant.

Static-friendly. Optional Worker refuses `/episode`, `/timeline`, `/chain`, `/flap`, and `/arc` with 403 and stores nothing. No token markup. No allowlisted outbound href. No `emit`. No network. No clipboard. No storage. No live page write.

## Disconfirming evidence (design material, not a measurement)

The pin would be the wrong object if a human later seals an independent record into a different ledger with its own hash, under a named source, without this page joining it to a neighbor. A dispatch log or radar file that fixes a clock time would be evidence about a calendar claim in the scan, not a reason for this page to draw a line. A pre-registered empty rail that stays empty when no second sealed record arrives is the behavior this draft copies. A narrative that names the next beat is the behavior it refuses.
