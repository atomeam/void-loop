# F-046: WebGPU Volumetric Thought Injection Mind

**Ledger ID:** F-046  
**Slug:** F046-webgpu-volumetric-thought-injection-mind  
**Date:** 2026-10-17  
**Status:** Prototype (runnable)

## Concept
Novel combination of a 3D volumetric density field (WebGPU compute preferred, Canvas2D particle-projection fallback), a local Worker-based neural policy agent that reasons over pointer + orientation inputs to produce thought-injection vectors (seed position, intensity, channel bias), CSS morphing of the Void chrome driven by the agent's internal activation entropy, and optional Web Audio spatial modulation of field energy. Pointer and orientation seed the volume; the agent injects coherent "thoughts" that evolve the field; field statistics feed back to the agent and morph the UI. Seal persists the best policy weights.

Not a superficial variation of prior experiments:
- Not 2D NCA or lattice (F-036, F-045, F-039): true volumetric 3D grid with projection.
- Not discrete agents or boids (F-020, F-025, F-040): continuous density field driven by injected thoughts.
- Not pure spectral or vector fields (F-034, F-033): agent-mediated injection closes a reasoning loop.
- Not living cards or portals alone (F-038, F-045): morph + audio + volumetric feedback.
The mind reasons spatially and injects into the volume; the volume's response reshapes both the mind and the surrounding interface.

## Architecture
Single self-contained `index.html`.
- Main thread: requests WebGPU adapter/device if available for compute dispatch of volume update (64^3 voxels, simple diffusion + injection); falls back to Canvas2D particles with depth projection; samples volume for energy/entropy proxies; manages CSS morph on root; optional AudioContext oscillators panned by injection location; handles pointer and DeviceOrientation.
- Blob Worker: small feed-forward policy (8–12 weights) that maps (pointer_x, pointer_y, orientation_alpha, beta, field_energy) → (inject_x, inject_y, inject_z, intensity, hue_bias); evolves weights via simple mutation on fitness (coherence of injections vs field response); returns policy ~2 Hz.
- Fallbacks: no WebGPU → Canvas particles; no Worker → fixed injection; orientation denied → pointer only; audio blocked → silent; storage blocked → visual seal only.

## Expected outcome
Interactive 3D-ish volumetric field that develops coherent structures from thought injections generated by a local agent; page chrome hue/blur/scale morphs with agent entropy; optional spatial audio pulses with field energy; sealed policies remember successful injection strategies. Fully offline-runnable.

## Mechanics
- Volume: each voxel density updated by neighbor diffusion + decay + additive injection kernel centered on thought vector.
- WebGPU path: storage buffer of floats, compute shader averages 6-neighbors + inject, render via raymarch or slice projection to canvas.
- Agent: tanh activations on linear layers; fitness = correlation of injection locations with subsequent high-density regions + moderate energy.
- Morph: agent entropy → hue-rotate, filter blur, transform scale.
- Seal: truncated SHA-256 of weights + fitness + timestamp → localStorage.

## Failure modes
WebGPU unavailable → particle fallback; large grid may drop frames on low-end devices; orientation permission prompt may be denied; audio autoplay policy may silence; Worker may be blocked by strict CSP.
