No account and no token: your browser reads GitHub's public API, 60 requests an hour without a login (an unchanged answer, a 304, is free), and the last copy of each repo stays on this device and opens offline.

How it works, limits and keyboard shortcuts
  • Your browser reads GitHub's public API directly. There is no account, no token and no server in between, and nothing about you is sent anywhere else.
  • GitHub allows 60 requests an hour from one network without a login. The first look at a repo reads up to its 2,000 newest items (one request per 100, so at most 20); after that, Refresh asks only for what changed since the saved copy, with the saved ETag, and an unchanged answer (304) does not count against the limit.
  • When the limit is used up the page says when it resets and keeps showing the saved copy. The last copy of each of six repos stays on this device and opens offline.
  • A pull request is any item GitHub marks with a pull_request field; its merge time comes from there too. Times show in your own time zone; exports keep UTC.
  • Keyboard: / jumps to search, r refreshes, e downloads the CSV, and the arrow keys move between the Issues and Pull requests tabs.
