PDF studio

Make a PDF smaller, join it, split it and tidy its pages in a few clicks. Compress with a strength you choose, convert pictures to PDF and PDF pages to pictures, rotate, number, stamp and crop. Every file stays on this device.

Use with PDF tools Merge PDF files Organize PDF pages Resize an image All tools
Every tool runs on this device with a small open-source library (pdf-lib and pdf.js, both vendored here): your files are read, changed and saved in this browser and never uploaded. After one visit the page works offline. A password-protected PDF cannot be opened, and text in a PDF cannot be edited (a PDF holds no paragraphs); ask questions about a PDF reads one instead.
