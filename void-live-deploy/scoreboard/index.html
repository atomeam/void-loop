Where the numbers come from

  • Tasks and success: the outcome exam (/progress/) and the site tester (tester-log.json).
  • Uptime: the hourly guards (status, /api/status).
  • Deploys: commits merged to main on GitHub (each one deploys).
  • Head to head: tower.evidence.json, losses included (/compare/).
  • Bots: bots/registry.json, each bot counted only when its test passed.
  • Money: the public ledger (/treasury/).
