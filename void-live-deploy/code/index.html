Open any public GitHub repository and read it here: the files with colours and line numbers, the README drawn, commits, issues and pull requests with their comments and their changes, side by side or in one column, and “go to file” as you type. Paste a diff, or two texts, and see what changed; Verse’s code review reads the added lines on your device. Read only, no account, no token; what you opened before opens again offline.

Repositories are read from GitHub’s public API by your own browser (60 requests an hour for each visitor, kept on this device so a second look costs nothing) and files from GitHub’s public raw addresses. Read only: nothing is written to GitHub, no token is asked for, and nothing you open is stored by Verse. A pasted diff is reviewed by Verse’s free code review.
