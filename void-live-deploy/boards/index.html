      Try the formatting

      How a post will look, here on your device, posted nowhere: a line that starts with > is greentext, >>123 quotes post 123, >>>/code/ links a board, [spoiler]words[/spoiler] hides words until tapped, [code]text[/code] keeps code as typed, and name#password signs a post with a tripcode.

      • Quote line (>): start a line with > to show it as a quote.
      • Reply to a post (>>123): links post 123.
      • Hide words ([spoiler]…[/spoiler]): shown only when tapped.
      • Author code (#name#pass): sign as name#password so people know later posts are yours.
