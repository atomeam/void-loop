Security

How Verse keeps the site and its members safe, and how to tell us when something is wrong.

Accounts

  • Sign-in uses passkeys. There are no passwords to steal or leak; we store only the passkey's public key and a random account id.
  • "Forget me" deletes an account and everything tied to it at once.

The site

  • HTTPS only, with HSTS so browsers never fall back to plain HTTP.
  • A strict Content Security Policy and a Permissions Policy that turns off camera, USB, Bluetooth and other device access the site does not need.
  • Hosted on Cloudflare. IP addresses are used only for rate limiting, hashed and kept for at most two minutes.
  • Incoming webhooks (such as GitHub's) are checked against a signed secret before anything runs.

Payments

  • Checkout is handled by Gumroad. Verse never sees card numbers. License keys are stored only as a one-way hash.

How changes ship

  • The code is open: github.com/atomeam/void-loop.
  • Every change goes through a pull request with automatic code review and hundreds of automated checks before it reaches the live site.
  • Hourly guards watch the site; results are on the status page.

Report a problem

Email atom@a-to-mind.com. A machine-readable contact is at /.well-known/security.txt. Please give us a chance to fix it before sharing it publicly.
