Is this photo or video AI-made or edited?

Drop a file and Verse reads what it says about who made it: Content Credentials, the AI source type, generator settings, the editor that saved it and the camera or phone that recorded it.

What this can and cannot tell: it reads the file's metadata and Content Credentials, the way a forensic examiner's first look does. It does not judge the pixels. Metadata can be stripped (most social apps strip it) or faked, so "no signs" is never proof that a file is real. To check that a Content Credentials signature is valid, open the file at contentcredentials.org/verify.
