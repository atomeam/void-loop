Trend 50/200

Holds the coin while its 50-day average is above its 200-day average, and holds cash otherwise.

  • Buy at the next open when the 50-day average of closes is above the 200-day average.
  • Sell at the next open when it is not.
  • Decided on the daily close (00:00 UTC), traded at the next open. Long or cash only.

Risk: every number here is a backtest on past prices. Past results do not predict future results, these rules have long losing stretches, and you can lose money. This is software you run yourself, not financial advice. Verse never sees your exchange key, never holds your money and never places a trade.

Walk-forward test

The honest check: each year, the settings that did best over the three years before it (from a small grid) are picked, then run untouched on that year. Those years were never seen when the settings were picked.

Every trade

Run it on your own account

  1. Install Node.js 18 or newer.
  2. Download the bot: (its config already says trend-50-200), or in a terminal: 
    mkdir verse-bot && cd verse-bot
curl -fsSLO "https://a-to-mind.com/trading-bots/kit/{bot.mjs,strategy.js,arb-scan.mjs,arb.js,arb.example.json,package.json,config.example.json,README.md,LICENSE}"
npm install && cp config.example.json config.json
  3. In config.json set bot (trend-50-200), your exchange (a ccxt id such as kraken or coinbase), the symbol (such as BTC/USD) and budget, the most it may ever spend on one buy.
  4. Paper mode first, no key and no trades: node bot.mjs. It prints the day's decision and keeps a pretend balance.
  5. Live when you are ready: make an exchange API key with trade permission only, never withdrawal, put it in EXCHANGE_API_KEY and EXCHANGE_API_SECRET, set VERSE_BOT_LIVE=yes and run node bot.mjs --live --loop on a computer that stays on.

The files: bot.mjs, strategy.js (the same file this page runs), arb-scan.mjs and arb.js (the read-only arbitrage scanner), package.json, config.example.json, README.md, LICENSE (MIT). Spot only, long or cash, no leverage; it only sells coins it bought itself.
