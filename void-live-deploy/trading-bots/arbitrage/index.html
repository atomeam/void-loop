Arbitrage scanner, net of every fee

Buy a coin where it is cheap and sell it where it is dear: this reads each venue's order book right now and works out, for a $1,000 trade, what you would end with after both taker fees and the gas on a Uniswap leg. Most of the time the honest answer is less than you started with.

Risk: prices move in milliseconds and faster bots close real gaps first, so a gap shown here is not money in hand. Selling on one venue what you bought on another needs coins and cash already on both, or a transfer that takes time and costs a fee. Verse only reads public prices: it never trades and never holds money or keys.

Run it yourself

The same math, on any exchanges ccxt supports, with your own size and fees, from your own computer. Read only: it never places an order.

mkdir verse-bot && cd verse-bot
curl -fsSLO "https://a-to-mind.com/trading-bots/kit/{bot.mjs,strategy.js,arb-scan.mjs,arb.js,arb.example.json,package.json,config.example.json,README.md,LICENSE}"
npm install && node arb-scan.mjs --every 30

For agents
