Lightweight Page

This page is for anyone who wants a page that stays readable, and a way to weigh how much markup another page is carrying.

The original: motherfuckingwebsite.com

This page is dark, like the rest of Verse. It uses the site's own type. No extra font file, and no picture. The words stay put if you turn style and script off.

Weight is a choice. A picture standing in for a button, a font that must arrive before the sentence, a script that runs before you can read: that is a slow page. Write the sentence. Link the next page. Stop.

Weigh some markup

Paste HTML. You get the byte count, and how many pictures, font requests and scripts are in it. Nothing is uploaded anywhere else.
