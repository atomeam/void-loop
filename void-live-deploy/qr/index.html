QR Code Maker

This page is for anyone who wants a code a phone can scan from a link, a Wi-Fi network, or a contact.

The original: myqrcode.com

Type a link or a short line. The page draws a code a phone can scan, and you can download that drawing. The work stays on this device. A line that is too long is refused. The page uses the strongest error correction that still fits the same size of code.

How to use it

Hello is a short line, so the code is version 1. Open it here: hello. A phone reads the squares. The quiet margin around them is part of the code, so leave it when you print.

Dark and light are the two colours. They need to be different, or a phone may not read the code. Download SVG keeps the drawing sharp at any size. Download PNG is a picture for a slide or a post, and it needs scripts. Press Make if scripts are off. The address still draws the code.

A Wi-Fi network

Put a network name and a password here. The button writes the line a phone expects, and the code above uses that line. The password is in the code. Anyone who scans it can join the network.

A contact

A name, a phone number, and an email become a contact card in the box. The code holds that card. It does not look the person up.

What this page leaves out

This page draws the code on your device and does not keep a copy. It does not count scans, it does not let you change the destination later, and it does not put a logo in the middle. A logo can cover the squares a phone needs. Frames, pattern shapes, and a JPG download are not here. PNG and SVG are.
