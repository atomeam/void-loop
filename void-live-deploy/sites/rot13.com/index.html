Rotate letters

Type anything. Pick how many places to move each letter. Other marks stay put. Thirteen places is its own undo: run it again and the words come back.



Where rot13.com came from


rot13.com rotates letters. The first copy the Wayback Machine saved, on 19 April 2001, was a few words: “rot13.com awesoma powa!” Who made the site is not on the page, and this history does not guess.


The cipher it is named for is older than the site. Wikipedia describes it as a letter substitution that replaces each letter with the one thirteen places on, a special case of the Caesar cipher used by Julius Caesar in the first century BC. The same article says the name is also written rotate-13, or, rotated, the letters themselves shifted.


On 10 November 2026 the live page offered every shift from one place through twenty-five, pointed its about link at that article, and asked for JavaScript before it would run. This page does the same job, on your machine, with the history beside it.
