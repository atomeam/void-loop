Progress: what Verse can actually do

The outcome exam. Each line is an ask whose result is fixed, and below it the score a visitor would get on a phone-width page: the right skill, a result in 12 seconds, and the thing the ask named. A pull request that makes a passing one fail is not merged. Verse reviews the pull request and merges it when the review, the merge gate and this exam pass. Spending money, and a message sent to someone outside, still wait on the confirm line. A song counts when an audio file plays and the title and artist match. Counts of skills, pull requests and lesson sentences are not a score.
