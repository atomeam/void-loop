About the data

Models and datasets are read live by your browser from the Hugging Face Hub's public API (no key; the Hub limits how often one address may ask, so a result is kept on this device for ten minutes). Every name links to its page on Hugging Face, where its files, discussions and full card are. Card texts belong to their authors. Sizes come from the files' own parameter counts; a size marked "from the name" is read off the model's name.
