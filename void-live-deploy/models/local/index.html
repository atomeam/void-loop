    An 8B model at Q4_K_M has about 4.9 GB of weights and needs about 5.9 GB to run.

    Weights take parameters × bits ÷ 8 bytes; running adds about a fifth for the conversation's memory and the program. A rule of thumb: long conversations need more.

    Quantization in plain words

    A model is billions of numbers. Stored at full precision each takes 16 bits; a quantized build rounds them to fewer bits, so the file is smaller and runs on less memory, at the cost of a little accuracy. Q4_K_M keeps about 4.8 bits per weight and is the usual choice; Q8_0 is close to the original at about twice the size.

    How to run one

    1. Install Ollama or llama.cpp (both free and open source).
    2. Copy the command under Files and paste it into a terminal: the file downloads once, then runs offline.
    3. Talk to it in the terminal, or open the address the program prints in your browser.

    About the data

    The list is read live by your browser from the Hugging Face Hub's public API (models tagged GGUF), with each repository's file list and sizes. Every model links to its page on the Hub. The commands use features of Ollama and llama.cpp that fetch a GGUF straight from the Hub.
