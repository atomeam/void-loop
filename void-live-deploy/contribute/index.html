Assimilate: build Verse with us

Verse is open source at github.com/atomeam/void-loop. Every bot and skill below links to its code. Members help build Verse: if you can make one better, or add one that is missing, send a pull request.

How to add or improve a skill

  1. Fork the repo and make a branch.
  2. Skills live in void-live-deploy/skills/. Copy one close to what you want and change it. Bots are listed in bots/registry.json with a real test input and the answer it must give.
  3. Run npm ci then node tools/pre-pr.mjs. It runs the same checks the site runs.
  4. Open one small pull request that does one thing. Automatic review and the test suite run on it; when they pass, it ships to the live site.

Rules of the road are in AGENTS.md and STANDING.md. A bot goes live only after its test passes on a real task.
