Regex Tester

This page is for anyone who wants to try a search pattern against a sample and see each match marked.

The original: regex101.com

Type a pattern and a sample. Every match is marked. The work stays on this device. A pattern with a repeat inside a repeat, such as (a+)+, is refused so the page cannot hang.

More text tools: Base64, word counter, unit converter, rotate letters.
