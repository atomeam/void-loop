Regex Tester

This page is for anyone who has a search pattern and wants to see what it matches, what each piece means, and how a replacement would rewrite the sample.

Type a pattern and a sample. Every match is marked, listed with the character it starts on, and read back in a short sentence. A replacement box rewrites those matches. The work stays on this device, using JavaScript's own regular expressions. A pattern with a repeat inside a repeat, such as (a+)+, is refused so the page cannot hang.

What the pattern means

  1. `\d+` means one or more digits.
  2. Every match is listed, not only the first.

Replacement

Nothing is rewritten until you type a replacement. $& stands for the whole match, and $1 stands for the first saved group.

How to use it

The sample starts as "call 555 or 911", and the pattern \d+ means one or more digits. That finds 555 and 911. The first character of the sample is character 1, so 555 starts at character 6.

Put (\d+) in the pattern and [$1] in the replacement. The parentheses save the digits, and $1 puts them back inside brackets. Open that test here: digits in brackets. The result is "call [555] or [911]".

The flag i treats capital and small letters as the same. The flag m lets ^ and $ match the start and end of each line. The flag s lets a dot match a line break. The flag u turns on Unicode mode. This tester always lists every match, so you do not type g.

Copy matches puts "555 and 911" on the clipboard. The share link opens the same pattern, flags, sample, and replacement again. Press Test if scripts are off. The same address still holds the test.

Who made it

On 2 January 2013, InfoQ published an interview with Firas Dib. He said he had kept an IRC bot that explained regular expressions people sent it, and that the bot also ran a quiz. He said the bot was an extra mIRC client a friend ran, written in mIRC's scripting language, and that a text channel was a poor place for a long explanation. He said he started the website around the beginning of the previous summer, and that he rewrote the bot in PHP. He also said the layout came to resemble Rubular, that he used Rubular's quick reference and some smaller pieces, that the rest of the code was his, and that he had written to Rubular's author and put that credit on the site. Source: InfoQ, 2 January 2013.

The project wiki says the site has been created, developed, and maintained by Firas Dib, and that it started as a hobby project. It names six people who help with testing, documentation, and bug reports: OnlineCop, Zarthus, nhahtdh, TWiStErRob, working-name, and Doqnach. Source: the About page on the project wiki. The same wiki's FAQ, in Dib's words, says he has no plan to open the source. Source: the FAQ. The registry record above still does not name him. The 2012 copyright line and the interview are what connect the name to the site.

What came later

The project's own docs show six generations of the editor. They say the current application includes multiple test strings, a text pipeline, and a PCRE2 execution debugger. Source: regex101 docs, project history. The docs do not date each generation on that page.

What this page leaves out

This page runs JavaScript's regular expressions and nothing else. It does not step through an engine, it does not keep a library of patterns, and it does not run a quiz. The original's docs also describe more than one test string, a text pipeline, and a PCRE2 debugger. Those are not here. A pattern this page cannot read piece by piece is left as written, and the match list still uses the JavaScript result.
