Power Automate 429 "Rate limit is exceeded": why your flow is throttled and how to fix it

You see: 429 · Rate limit is exceeded

What it means

A connector your flow uses has its own limit on calls per connection in a time window. Your flow went over it, so the service answered 429 Too Many Requests and told you how many seconds to wait. Retries and pagination count as calls too.

How to fix it

  1. Open the failed run and find the action that returned 429; its connector is the one being throttled.
  2. Lower the concurrency on Apply to each (or on the trigger) so fewer calls run at once.
  3. Cut the number of calls: filter rows in the trigger or the List action instead of looping over everything, and use batch actions where the connector has them.
  4. Spread the work out: run the flow less often, or split a big run into child flows that each handle part of it.

If it keeps coming back

Flows that keep hitting limits can be slowed down, and a flow throttled continuously for 14 days can be turned off. Check the connector's Throttling section on Microsoft Learn for its exact numbers.
